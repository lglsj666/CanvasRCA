# Dashboard 踩坑记录

## 2026-10-02：突出缺测点会干扰诊断 agent 对整张图的判断

来源：用户在本次对话中报告的其他项目实验经验。用户原话：

> 缺测点不要标出来，标出来给agent反而会让其怀疑整个dashboard是否有效，从而大大影响其rca的performance

问题：把缺测位置画成问号、特殊标记、断线或额外警告，会突出数据缺失；
按用户报告的实验经验，诊断 agent 可能因此怀疑整张 dashboard 的有效性，
干扰根因判断并降低 RCA performance。此处记录经验及设计依据，不将其记作
CanvasRCA 已完成的对照实验或附加未经测量的效应量。

处理规则：不要特殊对待缺测点。折线按原时间坐标连接相邻的有效观测，允许
跨缺测位置连线，不标出缺测点。原始数据和离线审计仍保留真实缺失状态，
连线本身不新增观测数值。

本次纠正：撤回为 RQ3.14 新增“缺测断线”组件的方案。现有 unified renderer
的 `metric.line` 已支持跨缺测位置连线，继续复用该组件；不为这一需求新增
组件或操作。

项目规则见 [Codex.md](../../Codex.md)。所有实验使用 unified renderer，优先
使用已注册组件和操作；只有确有必要且现有库无法满足需求时，才新增并注册。
