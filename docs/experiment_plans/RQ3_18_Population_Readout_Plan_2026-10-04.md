## 1. 主线与真正需要解决的问题

**保留有效 M/R/L/G 证据，在同事实强文本基础上证明可分离的视觉根因排名收益，再研究降本。** 本轮不以图表问答、空白图片效应或换布局作为研究终点。

旧方案把大部分预算用于解释原生边际图为何有效；但 RQ3.16 已直接测试其去点增量，RQ3.17 又表明增加拓扑不能稳定改善排名。新的问题是：当前耗时证据的表达是否把“完整总体的典型耗时与尾部耗时”埋在紧凑嵌套数字中，导致模型混淆中位数、p95、抽样点和耗时类型？明确的总体读数能否纠正这种误读；在把这些读数清楚写成文本之后，视觉比较还能提供额外的 RCA 收益？

动机是可定位的工程/理解问题，不是已成立的因果解释：RQ3.16 报告中有把 parent median 4.866 ms 称为 p95（实际 252.88 ms）、把 inclusive span duration 称为 exclusive latency 的例子。原生图每阶段最多 32 个观测，是按父耗时秩抽样；尤其子耗时点并非按子分布均匀抽样，点云不能解释为总体密度。**这不说明旧图的数据错误，也不保证新图提高 MRR。** 原始样本、配对、二值摘要及全部基础证据继续保留于文本。

本轮只改耗时读数的呈现，不改变关系选择、候选、RCA 流程、评分器、模型或解码。公共数据和图形可读性没有解决的错误先在 CPU 阶段修复，不能靠追加推理来补救。

纯文本任务作两处表示中性措辞修正：删除“存在图像”的暗示，不新增诊断策略。所有臂使用相同系统和任务/输出要求；图像臂只添加同一固定读图说明。对比包含图像传输和该说明的整体表示效应，不声称只改变像素。

新增 `PopulationReadoutPacketV1` 引用原 `RequestPairPacketV1`。每关系按父、子两端各登记 reference/current 的 **p50 和 p95（完整合格总体计算）**、总体 n、抽样 n、inclusive 类型、ms 单位、实体及操作。保留精确浮点值、源字段路径与稳定字段 ID。原 trace/span ID、源行、时钟/单位来源及真值只留审计侧。严格递归白名单拒绝私有字段，不能在排除若干黑名单词后就称无泄漏。

F 文本按固定顺序重复上述**命名统计读数**，例如 `parent / inclusive / current / p95 = ... ms`；不含新的异常分数、比率、阈值或推荐候选。总体 p50/p95 均源于旧公共包，数值不重新从最多 32 个样本估计。基础文本中原配对事实、条件统计、样本点全部保留。

P 图在每个关系卡片内画四条对照行：parent p50、parent p95、child p50、child p95。每行 reference/current 两端圆点及一条中性比较线，横轴统一为 `log1p(duration_ms)`、刻度读数为 ms，四行使用同一范围，包含零和所有八个统计值。连接线表示两阶段统计量对照，不是时间轨迹、因果传播或 parent−child 的本地执行时间。确切数值、统计标签始终可见。总体与抽样数分开标注；图不表示原始观测分布或总体密度。不能从 p95 相减重建等待时间。

S 图沿用原生1120×800真实边际图及其样本。P/K 也采用1120×800、字体18、两列卡片和既有主题/颜色，但图元含义不同；P−S 是两种已有事实的视觉读数方案比较，**不能归因于某个单独几何变量**。K 与 P 仅移除圆点和比较线，保留相同坐标、数值、文字和几何位置，包括随数值定位的标签；因此 P−K 只检验新增图元，不代表全部空间信息。

无有效配对的9例所有臂完整回退文本，不画空面板、不警告缺测、不排除分母。关系选择/适用率不因结果调整；单关系及极值等用 CPU 合成边界样例验证。

## 5. 预注册检验、解释与停止

主要族固定四项，病例与事件组分别做同一个四项 Holm：

1. F−T：命名读数文本是否改善排名。
2. FP−F：视觉是否超过针对性强文本。
3. FP−FS：总体分位数图是否超过真实样本图（在同一 F 上）。
4. FP−FK：新图圆点和比较线是否有增量贡献。

次要族固定 S−T、FS−F、P−T、K−T、FK−F、P−K、FP−P、FS−S、FK−K、TR−T、FR−F、R−FP、R−FR、R−FK，以及三个交互 `(FS−S)−(F−T)`、`(FP−P)−(F−T)`、`(FK−K)−(F−T)`。只在相应交互经校正支持时谈“文本整理改变视觉收益”。跨数据集及粒度分解是描述/探索，不另挑显著项替代主要族。

双侧 Pratt-zero Wilcoxon，差值 round12，配对 dz，不报告 CI。模型无效输出记0；基础设施缺失保持未知，按比较自己的配对掩码分析，同时报告220全分母紧界限。原子已提交错误排名不重答。每次汇总同时提供 n 与失败类型、绝对 MRR、AC@1/3/5、Precision@1/3、三集 macro、修复/破坏、输出/成本与重复变化；历史平均值只能作为有暴露说明的参考。

采用依据：FP−F ≥.02，FP−FS 与 FP−FK 均正；这三项病例和事件组 pH 均<.05；三个数据集 FP 对 F、T 的 MRR 均正且 AC@5 不下降；R 对 FR、FK 方向与 FP 对 F、FK 一致；逐数据集 FP 实际 input＋output ≤ F 的1.10倍。F−T 不通过不自动否定可分离的 FP−F，但不得宣传文本整理已有效。若仅 F 改善，结论是文本读数改进；若只有样本图更好，不事后换预选方法。未通过则停止这个总体读数候选，不自动改画法/扩大预算。

功效限制：220例/193组固定，增加臂数不会增加独立病例，.02目标不保证可检出。正式前离线列出历史配对差方差与本轮样本量限制，但不由私有标签筛选病例或降低校正门槛。不显著写“未建立贡献”，不写“证明没有贡献”。

可信解释单独审核：固定哈希每数据集12例，全11臂；对实体/操作、inclusive类型、单位、p50/p95、总体/样本、阶段、数字与理由排名一致性、无依据因果断言逐项记录 supported/contradicted/unknown。额外离线统计误把median当p95等明确模式，抽取规则与人工审查分开报告；不能将正确排名等同正确理由，也不能把单人非盲审计当盲测总体错误率。无需新增模型调用。
