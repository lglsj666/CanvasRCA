## 修复对象与不变门槛

X_SRP 仍为固定 S_JOINT → R_PATCH_PACK → P_LOCAL_BI。S 在原公共池和原成本上选择，R 无权重新选择或删减 S 已选事实。组合的 R 输入是 S 的实际输出，分别登记完整池 R 与选择后 R 的资格；不再以完整池布局失败替代组合实际可行性检查。这是用户授权的前瞻性组合资格修订，不回写 v7 失败，也不声称恢复完整 2×2×2 因子归因。

字号至少18px、线条至少1.5px、图像N及保留K不超逐例历史U、全部选择后来源次数/数值写法/单位/缺测/样本/关系和候选不变。R须在每数据集至少50%病例减少同输入未packing锚点至少10%；同时报告对原S图的差异，不能把S删包收益记为R收益。P重算实际几何后沿用至少两个各≥8 token来源组、覆盖≥20%，每集≥50%。全部220病例留在分母，不用挑病例替换。

## 实现顺序

只使用 unified renderer；现有组件文件和默认行为不改。必要时新增并注册来源紧凑组件：复用原曲线/条形图，在同一卡片下方用紧凑流式字段说明保留完整记录，明确来源内字段绑定和局部共享前缀，减少重复字段名和留白；不得变成完整提示文字截图。现有布局、前景审计和操作复用。

先在隔离源码工作区修复并检查固定三例，再做全220例和实际processor、来源/图元/数值、几何、确定性、算子/缓存、恢复回归。原GPU正在执行的v7源码和渲染bundle不热改。回归通过后在原子调用边界排空旧worker、保存旧凭据与队列，部署兼容新增版本并追加X_SRP条件；旧请求身份和顺序保留，完成标记继续可信。用户GPU豁免单独记入凭据，不能写成已通过新的GPU测试。

CPU失败如实保留并修复，不修改Codex.md、不降低科学/几何门槛。运行能力的CPU验收不代表MRR提升，也不自动恢复其余取消臂。

## 显式字段语法修订

前三个原型显示仅减少留白或改成32px行高仍不足，不能靠不完整前景计数过关。新增来源组件允许固定、可逆的字段名缩写（例如 current→cur、reference→ref、parent→P、child→C、standard-deviation 字段→SD）；静态完整词典随统一读图说明提供。只改字段标签，不改任何字段值、数值字符串、单位或样本。对全部实际字段逐项反解并要求唯一恢复；字典冲突或无法反解直接失败。旧全字段名字串方案仍保留，不声称新旧像素/标签字符串相同。

这是新组件的可读编码语法，属于此次授权的大改实现；原有组件文件不修改。新增组件注册所需的 renderer 调度仅对新组件 ID 生效，旧分支和默认CSS均保留。CPU需验证旧图像像素完全一致。纯视觉任务提示可增加这份无病例信息的编码词典，不能带任何病例的观测或候选答案。

## 节点图与光栅复算

新增 graph.source_compact 仍使用实体节点＋有向、类型着色箭头，复用原分层节点顺序；只减小节点纵向内边距和层距，并保留全部节点、类型、边ID与方向。旧 graph.node_link 不修改。测量与实际绘图都使用同一新组件几何，禁止只改容量估算。

标签packing继续两轮有限整数偏移。若实际光栅和像素预测出现差异，最多两次撤回与差异格相交的已选位移，不搜索新位置，不读取模型结果；随后重新生成图与全量前景。最终预测必须与真实光栅完全相同，否则属于未解决实现错误，不准入。这处理了文本包围框里有其他固定图元时不能把其像素当成随文字移动的问题。

### 完整人口 CPU 反馈后的实现细化

首轮人口审核暴露两个实现边界：抗锯齿像素超出DOM框，及带第二行角色名称的图节点在文字移动后发生整节点重叠。修复使用与像素抽取一致的向外取整边缘，以及整个节点的实际浏览器边界作避让障碍；不屏蔽renderer审计错误。

原始贪心算法在总token数相同时只偏好最小位移，可能留下占格更散的文字，阻碍其他文字继续合并占格。新版先最小化总占格，再最小化当前文字块占格，最后按最小位移和固定坐标打破并列；仍是固定两轮、每轴±16px、同一事实和同一10%/50%门槛，不搜索模型结果。保留原CPU人口记录，新增路径重新审核全部受影响R输入；原S/P、QA及已通过模型算子不受此纯CPU编译修改影响。


最终布局复用已登记的 evidence_regions 与 DOM 测量：固定候选宽度、按高度确定性装箱，并保留完整卡片，不拆分来源记录。卡片在画布的位置可变化，但所有选中事实、卡片内样本及其来源顺序不变；不将这种工程修复称为仅改变像素对齐的单因素干预。旧无R九臂的像素和生成身份逐项保留。
