# CanvasRCA 下一阶段：视觉替换、诊断利用与 QA 脱节

日期：2026-10-05。状态：**研究计划已落盘；未实现后继实验，未运行新的准备、CPU/GPU 测试或模型调用。** 候选编号暂定 RQ3.19；正式协议、输入合同与执行凭据尚未生成。本文不改变 RQ3.18 已完成结果，也不继承其剩余调用额度或旧启动权限。

## 1. 共同主线与本轮决定

**研究遥测证据的表示方式如何影响模型的诊断决策，并据此构建更准确、更省成本的 RCA 方法。**

两条线同步推进，共享病例、事实包和对照：

| 方向 | 本阶段的具体工作 | 交付与决策 |
| --- | --- | --- |
| 方法优化 | 一个候选：在完整事实保留的前提下，采用无损紧凑文本，并将确能由图准确承载的指定事实移到图中 | 比较 MRR、覆盖和完整请求成本；决定是否冻结候选 |
| 现象与机制 | 主问题是附加视觉与重复证据如何影响排序；同时开展新的轻量 QA→RCA 干预实验 | 区分读取、绑定、比较与诊断利用；为表示分配提供约束 |
| 辅助测量 | 先资格验证轻量 attention 记录；通过后做有上限的标题干预 | 提供定位证据，不阻塞前两项，不把热图当因果解释 |

研究目标继续是 **MRR 接近 0.60，实际成本相对强对照最多增加 5%，优先下降**。这是联合目标，不是保证达到的结果。输入减少、输出减少、推理时间减少分别记录；不能用其中一项替代全部成本。

不再把每个部件都显著作为承认整体收益的前提；整体方法、特定视觉贡献、特定机制解释分别按对应对照判断。也不通过删掉强基线的有效证据、削弱其提示或增加其无用输入制造视觉收益。

本计划取代早先“先依赖 QA 校准选择表示”的未定候选：**QA 与 RCA 的联系本身需要新干预验证，暂不将 QA 分数直接作为方法路由器。** QA 支线是真实的新实验，不仅复用历史材料。

## 3. 方法候选：完整事实上的视觉替换

### 3.1 四臂，共 880 个开发位置

沿用 220 个已暴露 eval 身份：AIOPS-2022/2025 各 60、AegisLab 100。四臂共享候选、五候选输出、评分器、基础任务说明、模型和解码。

| 代号 / Arm | 输入 | 主要用途 |
| --- | --- | --- |
| F / FULL_TEXT | 冻结 RQ3.18 `READOUT_TEXT` 的完整强文本，以本轮新调用获得结果 | 保留已经整理过读数的强基线 |
| C / COMPACT_TEXT | F 的无损结构化紧凑表示；保留全部事实与阅读规则 | 测量纯文本组织与压缩，不将其收益归给视觉 |
| A / ADD_VISUAL | C＋固定总体耗时图 I＋固定读图说明 | 与当前附加图片路线建立同期比较 |
| **V / REPLACE_VISUAL** | **从 C 中移除登记集合 S 的文本副本，加入与 A 相同的 I 和读图说明** | **唯一预选方法：检验视觉替换的排名与成本收益** |

I 固定复用 RQ3.18 的 `trace_profile.quantiles` 表达与 1120×800 画布、字体18、阶段颜色和尺度。不在本轮比较原生样本图、总体图、拓扑或新布局；选择总体图是为了明确可移交的统计事实，不是宣称它已胜过原生图。

原有 9 个无合格配对病例完整回退 C，保留在 220 分母。普通完全相同请求只可引用本轮提交；重复臂重新调用。不得使用历史回答替代 F/C/A 的同期对照。

### 3.2 可审计的事实与载体合同

先形成公共事实账本。每项至少绑定：实体、操作、模态、阶段/时间、单位、统计类型、精确值或原字符串、支持数量、关系方向、来源键与呈现位置。原始身份和私有评价标签留在审计侧，不进入请求。

紧凑 C 允许把重复 JSON 字段、单位定义、共同实体标识写成显式列头或局部字典；不能合并不同观测、删除“正常”证据、截短日志、减少序列点数、改变参考窗口或隐藏支持数量。当前输入已有稀疏序列等紧凑格式，不把重复实现这些功能当新增方法。候选与输出规则、现有诊断任务和核验说明保持一致，不借压缩悄悄更改推理策略。

集合 S 只包含图上确实可见且能准确恢复的事实：相应父/子实体及操作、两阶段的总体 p50/p95、单位、inclusive 类型与支持数量等。它不包括原始配对样本、额外分位数、M/L/G 事实、局部执行时间或推测的因果结论。每个被删文本事实必须有明确的可见图元接收；机器侧 `data-value` 不算模型可见证据。

**当前实现有一个必须先解决的缺口：总体图数值标签经格式化，DOM 中的完整数值不代表图片中存在完整精度。** 默认优先将不能精确显示的值留在文本。若需要增加精确显示选项，必须在 unified renderer 注册必要选项、保留历史默认语义，并让 A/V 使用同一新图；不能缩字体、裁极值或把长数值藏到不可见字段。若固定尺寸容纳不了，保留文本并记录未转移，不制造精度等价结论。

关键核对为：`unique_facts(F) = unique_facts(C) = unique_facts(A) = unique_facts(V)`。另外分别记录各事实的出现次数、文字 token、可见图元和精度。V 必须真正移走完整正文中 S 的对应表达，不只是取消 RQ3.18 F 新增的重复读数段；否则实质回到已做过的 P/FP 比较，应在 CPU 阶段取消该候选。

选择 S 只能使用公共字段、显示可行性和固定规则；不得使用真实根因、历史得分、数据集名称或当前模型回答。全部规则在首次新模型调用前冻结。

### 3.3 每个比较能回答什么

- V−F：最终方法能否超过现有强文本；包括紧凑组织及视觉替换的整体作用。
- V−C：在同一事实基础上，视觉载体及必要说明能否超过紧凑文本。
- A−C：完整紧凑文本保留时，附加图像的效果；与历史退化建立可比的同期观测。
- V−A：相同图像下移除已转交的文字副本是否有帮助；同时改变重复次数和长度，**不能单独解释为 attention sink 或纯重复机制**。
- C−F：无损文本组织效果，是必要强对照而非视觉收益。

这个结构与 RQ3.18 的“重复摘要×加图”不同：该轮各臂仍保留全部正文；本轮核心是可审计的跨载体事实移交。若最终没有实际移交，或者只得到文本压缩收益，应据实收缩结论。

## 4. QA 脱节：60 例、480 次新增调用的配对实验

### 4.1 三个待区分的解释

1. **测量错位**：旧 QA 测了容易读、却不影响该次诊断的内容，弱相关来自题目选择。
2. **绑定/比较瓶颈**：数字可读，但实体、操作、单位、阶段或同统计量比较失败。
3. **诊断利用瓶颈**：相关事实可正确回答，辅助读取也改善了 QA，但 RCA 排名没有同步改善。

新实验不预先选定哪个成立。只有观察性相关不能区分它们；提供正确读数也可能改变注意与显著性，因此干预结果不能被包装为对内部感知变量的完全因果识别。

### 4.2 病例、题目与答案来源

从方法线 220 例按固定哈希选 60 例，每数据集 20 例，优先不同事件组。资格仅依公共字段和题目是否能构建，不按 QA 错误、RCA 失败、真实根因是否命中或图像收益挑病例。记录不足及跳过理由；身份列表在调用前冻结。此小样本只用于机制开发，不能代替全量 MRR 评价。

每病例固定 6 题，2 题一层，答案由公共事实确定性计算并在调用前保存：

| 层次 | 题目类型 | 单独得分的原因 |
| --- | --- | --- |
| 读取 | 指定字段精确数值；单位/耗时类型 | 区分数值读错与诊断判断错误 |
| 绑定 | 数值对应的实体、操作和阶段；一条真实关系的方向/端点 | 防止“数字正确、属于谁错误”被算作读对 |
| 比较 | 同统计量两阶段变化；同单位同统计类型的实体间比较 | 检查模型是否将可读值正确用于比较 |

每套题至少覆盖一项可转移 S 的事实及一项保留在文本的 M/L/G 事实；其余按预先写定的公共模板填充。不能拿独立 p95 的差当局部执行时间，不能把 inclusive 与 exclusive 混比，不能依据跨主机时间推断关键路径。不问“哪个是真根因”，不将故障注入标记或评价答案用于出题。

同时保存运算依赖和源字段。数值评分按源精度及登记的单位换算容差，实体/方向按明确集合判定，不让诊断模型或另一个 LLM 自评。题目答案与 RCA 标签分开存储；历史答案从不成为公共证据。

### 4.3 每病例八次新调用，复用两次同期 RCA

对 C 和 V 两种表示分别执行以下四次调用，总计 `60 × 2 × 4 = 480`：

| 新调用 | 输入与输出 | 对应问题 |
| --- | --- | --- |
| Q0 | 原输入＋6题，输出简短结构化答案 | 自然读取、绑定和比较能力 |
| Q1 | 原输入＋正确绑定读数卡 B＋同6题 | 辅助读数是否真的改善测得的 QA，而非假设已经改善 |
| RB | 原 RCA 输入＋B，保持固定五候选 RCA 输出 | 辅助读取的诊断效果 |
| RP | 原 RCA 输入＋等事实对照 P，保持相同 RCA 输出 | 控制新增事实重复与突出本身的影响 |

两种表示的原始 RCA 使用主实验 C/V 同期结果，不额外请求，不把 QA 和 RCA 放进同一次对话，不把 Q0/Q1 的模型回答传给 RCA。

QA 调用复用相同证据，任务区统一替换为冻结的六题模板及 QA 输出 schema，不同时保留“输出五个根因”的冲突要求。C/V、Q0/Q1 使用相同 QA 模板；RB/RP 保留原 RCA 模板。两项任务提示不同是测量边界，QA 正确不等于模型在无提问的 RCA 中主动提取了同一事实。

B 是由公共答案编译的自包含正确读数：按问题组织实体—字段—单位—阶段及所需比较结果。P 含**完全相同的正确事实和比较结果**，按来源账本顺序呈现，保留明确实体标签；不故意打乱归属、制造错误或削弱可读性。B/P 使用相同词汇和字段模板，仅改变组织及分组，对实际 token 差异预先审核并报告，目标差异≤2%，不用无意义填充凑长度。相同图像与原 RCA 提示保持不变。若 B/P 编译成同一请求则记为无操纵，不为凑位置反复调用。

RB−RP 测量的是**正确事实的任务对应组织**，不是“新增真实知识”或纯感知修复。Q1−Q0 仍包含重复呈现效应。两者结合用于约束解释，不能替代正式的中介因果模型。所有病例接受相同登记干预，不只给 Q0 错误者补答案。

### 4.4 分析与面向方法的反馈

QA 以病例为统计单位，先求三个层次准确率再等权平均；不能将360道相关题当360个独立病例。固定四项机制检验：Q1−Q0（C）、Q1−Q0（V）、RB−RP 的 RCA MRR（C）、RB−RP 的 RCA MRR（V），组成独立四项 Holm 族，病例与事件组分别报告。

Q0 的 V−C、分层 QA 与 RR 的相关、ΔQA 与 ΔRR 的相关、Q1全对但 RCA 失败比例，以及不同错误类型的修复/破坏作为探索结果。同步报告主实验独立重复造成的排名波动，避免把一次回答差异全归给机制。60例的非显著结果不当作等效或独立证据，不按中途结果补样本直到显著。

源公开但是否与真根因直接相关，只允许在出题、身份和调用全部冻结后由评价侧注释，单独报告全样本与关联子组；不得反向筛题、重选病例或把此注释交给模型。

| 观察模式 | 对后续方法的含义 |
| --- | --- |
| Q0 单值高、绑定/比较低；B 同时改善 QA 与 RCA | 值得把可验证的实体/阶段组织融入下一冻结版本；本批次不事后改候选重跑 |
| Q1 明显改善 QA，RB/RP 仍不改善 RCA | 更支持“可读取不足以保证诊断利用”；不再用总体 QA 最大化作为路由目标 |
| QA 变化小但 RCA 改善 | 检查显著性、证据取舍和输出一致性；不声称提升来自感知能力 |
| 只在评价后认定的根因相关题目上出现关系 | 旧 QA 可能测量错位；该子组属于探索，另需冻结验证 |
| 操纵无效、天花板或样本证据弱 | 如实记录测量限制，不宣布“QA 对 RCA 没用” |

## 5. Attention：低储存资格与有上限的辅助干预

沿用 [轻量记录与 sink 讨论](../../important_docs/CanvasRCA_Attention_Storage_and_Sink_2026-10-05.md)。先资格验证，默认关闭；方法与 QA 的运行不等待它无限期完成。

在线累计有限 full-attention 层、两类查询位置、预定义语义区域、粗空间网格及少量 top-k。禁止保存完整逐步 attention；不能把混合架构的线性注意力层当普通 softmax attention。语义区域依据实际 processor 合并后的图像 token 映射；先按真实区域积分，再输出粗网格。

储存合同保持每次普通记录最多65,536字节，每10,000次另允许100份1MiB细节与32MiB共享材料：持久总量 **793,772,032字节**；再加64MiB临时缓冲，峰值 **860,880,896字节**，均低于十进制1GB。资格按实际分配空间、索引、元数据、失败/重试与临时文件一起计量，不能只报压缩张量体积。

最多36次/1,200秒做同后端 no-op 与采集兼容资格，核对输出、显存、吞吐和计数。若必须改变服务后端或读取算子，实验属于独立诊断副本，不混入主方法成绩。采集导致吞吐下降超过预设5%或占用超出已冻结资源上限时，不在主队列开启。

资格通过后，辅助上限为20个固定哈希、三数据集均覆盖的病例，每例4个条件，共80次：原图、移除固定页眉文字、将相同页眉移至保留的无数据区域、移除等面积且不含事实的装饰对照。全部经 unified renderer，仅在能保持事实区域与 processor token 不变时执行。没有可用空白/装饰的病例不能制造伪对照；先定公共几何资格和最终名单，缺额不按成绩补齐。

该小批次只定位位置/标题干扰与明显行为变化，不承担整体 MRR 提升证明。标题带密度高不等于标题文字本身有害；不得据此自动删高 attention token。VAR 类方法使用特定激活指标和选定注意力头重分配，不能直接套用旧模型阈值；本阶段不做 attention 重分配、模型训练或按热图自适应裁剪。

## 6. 统计、成本与采用决定

方法主要族只有 **V−F、V−C** 两项 MRR 比较，病例与事件组分别执行同一两项 Holm。V−A 是预先指定的机制比较；C−F、A−C 与重复差异作次要分析并分别完整报告，不靠增加十几个臂寻找赢家。全部沿用双侧 Pratt-zero、差值12位、配对 dz，不报告 CI。事件组先组内平均，再组间比较。

方法进入冻结扩展验证的门槛：

1. V−F 整体配对 ΔMRR≥0.03、V−C≥0.02，两项病例和事件组校正后均 `pH<0.05`。
2. 三数据集分别对 F、C 的 MRR 不下降，AC@5 不下降；任何数据集的损失单独公开，不用平均掩盖。
3. 固定60例的 C/V 独立新调用与初次比较收益方向一致；不得把同一输入的引用当重复。
4. 每数据集 V 的实际 input＋output 对 F、C 都≤1.05；GPU时间、CPU准备和失败成本同时披露。输入相对 F 下降10%是工程目标，不是已经实现的结果。

MRR≈0.60 是研究目标；即使满足上面的增量门槛但未达0.60，也明确保留差距。V−A 不显著不会自动否定已通过的整体方法，但不能宣称去重机制已成立。QA 和 attention 支线的显著性不作为掩盖主方法失败的替代条件。

成本用实际 processor、实际输出与服务计量；显式计入读图说明、字典、额外模型调用、重试和 QA/校准费用。研究期诊断开销与部署单次成本分开，若方法依赖校准则另报其摊销。固定模型大小和 reasoning 配方，避免把它们同时改变后宣称视觉降本。

模型无效回答保留零分；基础设施缺失保留未知，报告配对样本与原分母紧界限。超时 usage 不补0；若未知成本无法有根据地约束到门槛内，成本资格为未决。所有臂给出绝对 MRR、AC@1/3/5、Precision@1/3、逐数据集、病例加权及宏平均、修复/破坏、失败和重复差异。

解释审查复用 QA 60例，先对全部 C/V 原始 RCA 做预注册字段一致性筛查，再固定每数据集12例人工核对实体、单位、阶段、数值类型和理由/数组一致性。源核验范围与未知项单列，不能把规则筛查当完整语义审查，也不将排名提升等同解释可信度提升。

## 8. 实现前闸门、顺序与停止规则

当前只保存计划。未来获准实施后，在独立 RQ 目录沿用五功能模块和7,500行限制；所有执行入口默认关闭，以版本绑定凭据激活。

**第一步：静态检查后做CPU可行性。** 先检查源码、配置、白名单、关闭的启动入口和历史依赖；通过后才提取完整事实账本，编译F/C/A/V和QA包，用独立计算核对值、单位、引用、关系和阶段。检查所有病例的实际 processor token，`input+8192≤40960`，每数据集 V 平均输入对 F、C 都≤1.05。至少半数有图病例发生正文中的非空 S 移交，且 A/V 请求差异不是只去掉旧 F 追加段。若不能满足，停止此视觉替换候选，不删事实、缩字体、调整 processor 像素上限或放宽阈值。QA可保留为独立机制任务，改用已冻结的完整文本/完整加图对照；必须在调用前记录该分支，不能把它记成候选通过。

**第二步：完成CPU回归和实际例图审查。** 上面的可行性计算属于CPU资格的最前段，通过后继续其余检查。最多8个独立物理核worker，优先不同source/cloudbed。验证事实白名单、模块/行数、历史源保护、重复/引用、原子提交、恢复与预算；打开三数据集及长名称、零值、极值、单配对、回退例图，验证历史默认渲染不变。所有图经 `src/renderer/`；已有折线跨缺测点连接，不增加缺测符号，不改底层缺失数据。

**第三步：有界GPU资格。** 本地 Qwen3.8-27B、既有解码、context40960、输出适配8192、显存利用率0.75、并发36；不训练或增加模型。三个固定eval身份，共享18次/600秒，覆盖四主臂与QA/RCA干预接口。资格名单与覆盖表在启动前冻结。timeout-only按当前约束如实记录，不让语义或完整性失败伪装成超时通过；修复保留原耗费，不能反复重置smoke。

**第四步：方法与QA共同批次。** 固定哈希跨病例、数据集、臂交错，真实重复混入后半队列；避免一种方法全部先跑形成时间分块。QA为独立无历史会话请求；可与RCA交错，模型互不接收输出。冻结整个队列后运行，不按部分MRR改图、题目或调用次序。轻量采集如不兼容，关闭并保留其失败记录，不拖住主批次。

**第五步：完整批次后的决策。** 排空写入并审计所有终态后，分析方法和机制。方法达标则冻结再做扩展复核；方法不达标则停止该候选，完成QA机制结论和实证论文材料，不自动更换图形或追跑最高分臂。方法达标而某一机制不显著时，只收缩机制主张；反之机制有发现也不能包装成方法达标。

恢复信任原子完成标记，不在GPU加载后批量重开历史输入；错误输出不重答。只操作自有服务，按现行监控与关闭要求执行。实施和运行仍等待后续指示，本回合不进入上述任一步。

## 9. 新意边界与论文组织

本轮有价值的研究问题是：**为什么一个表示能被正确读取，却未必使证据被正确绑定和用于排名；跨文字与图像分配事实，能否改善这一过程并降低完整请求成本？**

已有研究直接覆盖来源分组、重复证据权重与不变性，因此不能把“按来源去重”当新发现：[Record Grouping Controls Evidence Weight in Language Models](https://arxiv.org/html/2609.08698v1)。本轮若成功，增量证据应来自跨载体事实移交的可审计实现、真实RCA上的准确率/成本，以及QA读取—诊断利用的配对干预；新意仍需与相关工作逐项核对，不能先保证首创。

图表感知研究区分编码与提取瓶颈，但不能直接推出读取成绩预测根因排序：[On the Perception Bottleneck of Multimodal Language Models](https://aclanthology.org/2025.findings-emnlp.573/)。视觉sink研究揭示部分高注意区域未必有相应任务贡献，提出有条件的重分配；它不等于删除所有高注意token：[See What You Are Told](https://arxiv.org/html/2503.03321)。本轮attention仅作辅助复核，不把直接移植VAR作为创新核心。

论文按三个层次组织：稳定的表示扰动发现；能区分读取/绑定/诊断利用的受控证据；在强对照上联合改善排名与成本的冻结方法。完整方法不成立时保留前两层及明确边界，不凭事后赢家编造统一成功故事。
