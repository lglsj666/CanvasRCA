# RQ3.16：边际分布图元与候选覆盖的受控验证

2026-10-03，America/Toronto。当前授权：设计、代码、静态检查、完整CPU回归、实际图像审查及有界GPU smoke；通过后停止。**不启动全量实验。** 单一主agent。工程资格不是MRR、解释可信度或部署资格。

## 主线、历史依据与本轮选择

主线保持“保留有效诊断证据，给视觉一个明确、可检验的比较任务，在强文本上证明排名收益”；先研究成本受控的收益，再研究压缩。本轮是RQ3.15结果后的新开发注册，不是将事后最优臂追认成成功，也不是恢复失败的二维联合图路线。

历史报告综合要求：RQ1.1支持选择性关系视觉而非全视觉；Tournament的oracle不是部署方法；RQ3.1/3.2表明选择器易破坏资源事实且恢复owner覆盖不保证恢复诊断；RQ3.3/3.4补充与核验不稳定且增加调用未抵偿成本；RQ3.5/3.6的screen优势可能在扩量消失，已有Top-1相近而Top-5下降的现象；RQ3.6-B/3.7具有条件性视觉正信号但未独立锁定绑定/布局机制；RQ3.8完整图有负结果；RQ3.10范围对照不足；RQ3.11有限数值保护没有带来收益且Top-5下降；RQ3.12可预测性不等于诊断相关性；RQ3.13状态图与截图近似且Aegis退化；RQ3.14的可靠增益来自WINDOW_TEXT，视觉未胜过markless；RQ3.15中MARGINAL均值最高，但联合图对它无优势、图元贡献未验证，Aegis列表缩短且覆盖下降。所有历史状态、分母、校正族与数据暴露分别保留，RQ3.9未完成不是零效应结果。

RQ3.15的关键已观察事实：MARGINAL整体MRR .4692、PAIR_TEXT .4280、BASE .4329，但不同分母的均值不能代替配对；联合/边际206/217相同MRR。Aegis联合图Top-1 45%→50%，Top-5 80%→71%，平均返回长度4.05→3.61；边际图也有Top-5损失。这些只是研究线索，不证明短列表是全部原因。

本轮问题：**父与子各自的reference/current分布位置比较是否提供强文本之外的收益？这种收益和覆盖损失，是否随允许返回的候选数量改变？** 使用真实数据点对照和输出容量析因，不再改选关系、删下降关系、换布局或根据gold路由。

## 冻结输入与八臂

完整沿用RQ3.15的220 exposed eval身份（A22/A25各60、Aegis100）、公共RequestPairPacketV1、原始M/R/L/G基础文本、连续配对文本、候选次序、参考/当前窗口、最多两关系和真实样本。已资格的数据不重新采集或重新选择；核验后复用211张原MARGINAL PNG。9例不适用者按相应输出规则完整回退基础文本，保留研究分母。原始Trace/单位/身份配对资格从冻结源与CPU审计继承，不假称重新处理所有原始数据。

| Arm | 输入及输出规则 | 作用 |
|---|---|---|
| BASE_FLEX | 原WINDOW_TEXT；原schema允许1—5候选 | 同期强基础锚点 |
| PAIR_FLEX | 原PAIR_TEXT；原输出规则 | 连续事实强文本 |
| MARGINAL_FLEX | 原PAIR_TEXT＋原边际PNG；原输出规则 | 事后候选的预注册同期复测 |
| BASE_FIVE | BASE内容；固定5候选 | 排除只给视觉增加候选容量 |
| PAIR_FIVE | PAIR内容；固定5候选 | 预选方法的同事实、同输出容量强文本 |
| MARGINAL_FIVE | PAIR内容＋原边际PNG；固定5候选 | **预选方法** |
| MARKLESS_FIVE | 完全相同文本、图布局、标题、轴、操作、样本量标签，移除数据点；固定5候选 | 检验真实数据点的增量作用 |
| MARGINAL_REPEAT | MARGINAL_FIVE的真实独立调用 | 稳定性，绝不择优 |

FIVE是显式RQ局部请求适配器：原JSON schema仅将services.minItems从1改为5，maxItems保持5；添加所有FIVE臂完全相同的简短输出说明。输出字段、合法实体、JSON判定、canonical scorer、MRR/AC定义均保持不变。不得补写候选、去重救分或改变采样/模型配方。模型无效回答仍按原评分零分。候选总数不足5时CPU失败，不能扩大候选或挑病例。

FLEX三个臂与旧输入精确对照，同时登记为**本轮同期独立复测**：为了将输出约束的效应与不同运行批次分开，必须在同一八臂队列中发起新调用；它们不是恢复或覆盖旧completed单元。所有新重复均计费、独立call identity，不将旧响应再当独立样本。旧RQ3.15结果只提供暴露开发背景和描述性稳定性参照。

原两端分布仍是最多32个按父耗时秩抽样的真实值，不是全总体密度估计。MARKLESS仍保留轴范围等信息，不称纯空白、完全无视觉或严格等像素控制。真实图/markless均保留全部数值文本，所以图形控制之间语义事实一致。没有文字截图臂。

## 统一renderer与最小更改

复用注册`trace_joint.marginals`及已有布局/appearance/indexing/spacing/component操作，不增加组件或操作。现有组件尚未消费通用`presentation.marks=false`；仅为它接通这一既有控制，默认绘制行为不变，并让renderer的预期绑定清单对应有意移除的数据点。历史默认图的代表性重新渲染必须逐字节一致。保存改变前源码、bundle指纹与所有被保护输入摘要；不覆盖历史PNG、manifest或冻结归档。MARKLESS由`src/renderer/`生成，禁止本地绘图库截图/擦除操作。折线与缺测规则不改。

## 注册统计与停止标准

正式矩阵仅登记：220×8=1760位置；9回退病例预计45个精确同输入引用，但MARGINAL_REPEAT全部真实发起。正式attempt上限1802，资格smoke最多18，总1820；历史RQ3.15等消耗不重置或合并成新独立样本。全量权限默认false，当前无正式执行授权。

主要Holm族四项，病例与冻结事件组分别同族校正：

1. MARGINAL_FIVE−PAIR_FIVE，全220。
2. MARGINAL_FIVE−MARKLESS_FIVE，全220。
3. MARGINAL_FIVE−BASE_FIVE，AIOPS120。
4. MARGINAL_FIVE−BASE_FIVE，Aegis100。

采用要求仍为四项方向均正且两层pH<.05；同事实文本整体ΔMRR≥.02、对基础AIOPS≥.03/Aegis≥.02，三个数据集分别对BASE_FIVE和PAIR_FIVE均正。另增加覆盖护栏：三个数据集分别相对BASE_FIVE与PAIR_FIVE，配对AC@5差均不得为负；这是工程采用必要条件，不是统计非劣证明。每数据集实际input+output≤BASE_FIVE1.20倍、PAIR_FIVE1.10倍。报告FLEX对照防止掩盖共同输出规则本身的损失。固定5不是保证安全，也不能靠填充第五名就声称推理改善，MRR、AC@1和理由一致性一起报告。

次要同一Holm族：三个FIVE−对应FLEX；MARGINAL_FLEX−PAIR_FLEX；PAIR_FLEX−BASE_FLEX；REPEAT−MARGINAL_FIVE；以及每病例交互差 `(MARGINAL_FIVE−PAIR_FIVE)−(MARGINAL_FLEX−PAIR_FLEX)`。另对同七项的AC@5做独立、明确标注的覆盖机制族。交互需要四臂齐全，以公共输入不变的随机交错请求比较整个schema＋说明干预；它不单独识别schema、措辞或解码内部路径。

沿用双侧Pratt-zero Wilcoxon、逐差round12、配对dz，不报告CI。模型失败计零；基础设施未知逐比较成对排除并报全注册分母[0,1]界限；交互按系数给合法极值，不硬套[-1,1]。完整绝对MRR/AC@1/3/5/AVG@3/5、pooled/macro、故障/粒度、repair/break、列表长度和input/output/图像成本均保留。每数据集固定hash12例×八臂解释审查，未核查断言保持unknown，不用confidence替代可信度。

本轮仍是已暴露开发，非独立确认；220例和事件组数不保证检测到小效应。四个部署/机制门槛任一失败，不选择事后最优FLEX或重复救结论；停止该边际图候选，不自动换布局、输出长度、选择器或test集合。若只有FIVE文本改善，报告输出协议效应，不叫视觉贡献；若有图而marks无收益，报告表示方案变化，不能称数据点计算有效。
