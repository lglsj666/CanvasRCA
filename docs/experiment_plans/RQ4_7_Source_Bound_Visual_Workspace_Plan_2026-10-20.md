# RQ4.7：单次诊断与两次视觉操作的来源归属实验

日期：2026-10-20，America/Toronto。状态：用户批准实施；本次仅代码和静态检查。

## 1. 决定与依据

单次调用是优先主线，两次调用是平行探索。共同问题是：正确读取数字后，
能否通过明确的来源、统计口径、阶段和视觉比较，提高根因排名？

RQ4.6 新纯视觉最高标准 MRR=0.3436，历史 A_UNIFORM_E50（U）为0.3517。
数值块覆盖改善未带来排名改善；实际输出存在 p50/p95 替换、正确数字归给
另一实体、正确 QA 与错误 RCA 并存。RQ4.4 SOURCE_ZOOM=0.3286，成本为 U
的约2.41倍，因此不把追加高清图本身作为新贡献。

预期贡献是“读取—来源绑定—诊断使用”的受控实证证据和可部署改进，而非
首次提出裁剪、多轮调用、引用编号或视觉推理。详见配套研究报告。

本轮只使用冻结 Qwen。跨模型验证推迟。本轮用户明确授权一次视觉动作调用
加一次诊断，构成对项目单阶段规则的**本轮例外**；仅操作已登记证据。
不改 Codex.md，不扩大为开放式多轮取证，不将 QA 答案传给 RCA。

## 2. 输入与视觉操作

沿用220个已暴露开发病例：AIOPS-2022/2025各60，AegisLab100。
保留历史 U 的完整概览、原始候选、处理几何、位置编码和保留索引。
全部 incident-specific 诊断内容只进入 unified renderer 图像；
任务、工具规范、读图及输出说明是病例无关文本。

视觉工作区提供：

1. CROP：指定区域原始像素。
2. CLOSED：保留该区域完整来源及实体、信号/操作、单位、统计口径、阶段、
   轴与关系端点。
3. COMPARE：来源完整视图加合法的并排对齐；仅兼容量纲、耗时类型及统计
   口径共用尺度。不兼容时保留 CLOSED 并记录实际操作。

至多两组操作，每组1–2区域，共至多四个来源单元。不得补取原始遥测、
引入新诊断统计、推测因果边或根因建议。原概览始终存在。
无法整组容纳的动作跳过；无有效局部图时仅使用原概览，不生成空面板。
模型无效动作与基础设施错误分别记录；不猜测修复、不重答动作请求。

### 六臂

| Arm | 操作与输出 | 问题 |
|---|---|---|
| S_COMPARE | CPU选取来源完整比较图；常规排名输出 | 比较表达是否有用 |
| S_GROUND | 相同图像；至多三条结构化观测后排名 | 单次预选：明确归属是否有用 |
| S_REASON | 相同图像；至多三条简短自由分析后排名 | 一般前置分析控制 |
| M_CROP | 共享模型动作，直接裁剪，第二次调用诊断 | 一般局部观察 |
| M_CLOSED | 相同动作，补齐来源后诊断 | 来源完整性 |
| M_COMPARE | 相同动作，合法对齐后诊断 | 两次预选：自选比较 |

CPU规则固定：M/R/L/G轮转；同来源不同统计/阶段和同口径不同来源构成候选；
按来源—统计—阶段组合数/预计图像token降序，稳定来源ID打破并列，
整组装入。数值大小、异常幅度、根因标签、旧回答和 QA 错误不参与选择。
日志/关系不强行数值化。不可唯一解释的字段不能臆造口径。

S_GROUND 的图像位置、实体、信号/关系、单位、统计、阶段和读数均由模型
输出，宿主只核验和审计，绝不纠正后重新排序。两种前置输出最多三条，
总输出8192，分别计费，不声称实际推理量相等。

三种 M 方法共享首轮操作回答，但部署成本各自计入完整首轮费用。
首轮输出只包含操作，不把解释、置信度或临时排名传入最终诊断。
S_COMPARE/M_COMPARE 共用最终编译器、图形操作及预算，比较完整选择方法，
不是相同最终输入的纯表示效应。

## 3. 预算和机制

局部工作区2048×2048，最多4096 merged image tokens；完整卡片不缩字、
不裁标签、不丢极值。新工作区处理后字号≥18px、线条≥1.5px，
每边≤8192。保留图像token总计≤16384，每请求输入+输出≤40960。
首轮输出≤512，最终输出≤8192。每图 processor 限制不变。
采用RQ4.4多图语义，编码前token和gather后token分开记账；
不能继承RQ4.6“所有图编码前总和≤16384”的单图限制而误删概览。

历史U、T_FULL、MARGINAL_FIVE只引用，明确运行时期/后端差异。
CPU侧预算检查不是模型已经读懂、降本或排名改善的证明。

固定哈希机制子集60例（每数据集20，优先不同事件组）：

- S_COMPARE、M_CROP、M_CLOSED、M_COMPARE各独立QA；
  三个S条件同图，不重复相同QA。
- 分解数值、实体、单位、统计、阶段和联合正确率，同时记录目标是否进入
  局部图。QA有独立任务接口，不继承根因排名指令。
- S_COMPARE/M_COMPARE增加两种仅QA干预：完整来源单元换位，答案不变；
  匹配语义标签交换，答案按可见标签重新登记。
- 合成QA不计算RCA；不可构造时NA，不依据答案改选病例。
- 阅读真实QA、观测断言和诊断理由，区分读错、来源错、正确但未采用，
  以及理由与排名冲突。模型解释不是内部推理的直接证据。

## 4. 分析和推进

同期主要族：S_GROUND−S_COMPARE、S_GROUND−S_REASON、
M_CLOSED−M_CROP、M_COMPARE−M_CLOSED、M_COMPARE−S_COMPARE、
M_COMPARE−S_GROUND。事件组 Pratt-zero 双侧 Wilcoxon为主要推断，
六项Holm；病例分析另报。差值12位、配对dz，不报告CI。
QA干预独立族，题目不当独立病例。历史比较是工程参照。

两个预选方法分别评价：对U标准MRR增≥0.02；三个数据集MRR/AC@5不下降；
每数据集全部input+output≤T_FULL的1.05倍；独立重复方向一致。
超过强文本约0.4846、争取约0.505是后续方向而非保证。
有完整系统进展就如实记录；机制归因只由相应控制支持。

报告标准/宽容MRR、AC@1/3/5、Precision、AVG、逐数据集/宏平均、修复/
破坏、非法候选、模型失败、基础设施未知及全分母界限；实际研究费用和
逻辑部署费用分开。记录绘图、两轮编码、prefill、生成、工具执行和端到端
时间，不用token下降代替加速证明。

## 6. 实施时明确的接口细节（首次调用前登记）

- 动作坐标是原始概览中的 `[left, top, right, bottom]`，归一化到0–1000；
  `focus`一个区域，`compare`两个区域。各区域必须完整落在一个来源面板内，
  不使用最近邻猜测。完整来源单元按原有面板及其绑定定义，不合并不同观测。
- 完整来源图保留原卡片。比较注释按原图阅读次序，最多取六个具有唯一
  来源/单位/口径绑定的数值字段；主图表字段先于明细。此上限限制附加
  比较注释，不删除原卡片或概览里的其他字段。原始数值字符串保留。
  共用尺度只用于相同信号、单位、统计口径且像素尺度一致的字段；
  阶段可以不同。尺度界限仅是确定性轴辅助量，不是异常分数。
  不满足兼容性时执行 CLOSED，记录实际操作；不把所有局部图都算作成功比较。
- 观测适配器只从登记的外层结构中读取排名，保留错误实体、重复及原顺序。
  观测声明的结构错误、精确来源元组匹配、不能自动核验的文字声明单独记录，
  不将声明核验结果反馈模型或改分。
- QA保留与对应RCA相同的完整概览及局部工作区。目标固定为最多六项：
  先按稳定哈希从局部视图并集中取至多三项，再从其余概览事实取至多三项，
  不足时按同一哈希补足。各臂使用共同语义目标，单独记录局部覆盖；
  局部没有目标时仍可从概览回答。干预同步作用于概览与工作区的对应副本，
  避免旧标签与新标签同时出现；不能同步完整修改时登记不适用。
- 位置干预交换两个完整且几何匹配的来源单元，目标随来源移动、答案不变。
  本轮语义干预明确限于匹配单元的**实体标签**：所有可见副本一起交换；
  若源文本还存在无法一致交换的身份副本，或几何/口径不兼容，登记NA。
  不交换一处标签后保留冲突副本。统计和阶段作为独立评分维度，未做其因果干预。
  每个病例最多六个共同语义目标；无法构造或无法定位的目标不适用而非错答。
- 独立重复保持同一种子和完整生成配方，但使用新调用身份；两次方法的
  重复重新运行动作和诊断。相同随机种子不意味着复用旧回答。
- Attention沿用目前兼容的第3层末个prompt query及首个decode query。
  不声称采集了观测字段或最终排名token的注意力。干预后的图像几何同步更新，
  工作区没有虚构的页眉区域。
- 冻结后90例验证分别考虑两条路线的推进结果；仅达标的预选方法进入，
  与同期T_FULL和U比较。两者均进入时上限450；只进入单次方法时270，
  只进入两次方法时360。空余不转给新臂。验证比较族在调用前固定为每个
  合格方法分别对U、T_FULL，单独Holm校正，不并入开发六项比较。
- 自动分析同时输出阶段耗时之和和同一运行会话内的实际在线链时间；
  后者包含研究队列等待，前者不能冒充连续冷路径。重启跨会话的间隔不用于
  部署时延结论。离线重型准备单独计时。

这些细节不新增实验臂或调用额度。可读性、容量、干预适用性、速度和
统计检出能力均未通过本次静态检查得到验证。
