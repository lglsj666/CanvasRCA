## CPU 定位后的修订记录

- 扩宽所有卡片会把原 SVG 同时放大，反而超出 N；单独扩宽完整图关系的原型也没有改善三个固定病例的锚点开销。因此不据此宣称压缩收益，保留原型审核记录。
- 新增组件内部采用同来源字段的阶段后置分组：相同量纲的 cur/ref 在同一显式标题下显示，保留原绑定 ID、数值字符串、单位和出现次数。只调整同一来源连续字段块的显示顺序，不移动原始时间序列的观测顺序。与旧图的区别登记为字段组织修订；独立 Python 读法与真实 DOM 对照，不仅检查隐藏属性。
- OFFSET 由显式注册的 `raster_translation` 执行，统一 renderer 完成正常绘图和审计后，精确复制证据及支持图的整数像素，移动相应屏幕坐标；固定页眉保持不变。只有原画布确有余量时才允许，禁止插值、裁图或扩大画布。新增该操作的原因是浏览器重新布局会改变少量 SVG 抗锯齿，不能用作严格的半格位移对照。
- CPU 整数偏移搜索采用已安装的 Numba 串行加速，不改枚举、约束、比较顺序和停止条件；16 个合成对照及两个完整真实图与原 Python 搜索结果完全一致。
- 当前文件系统剩余空间约 14GB；新增审核保留可无损恢复的压缩审计包，优先保护运行中正式结果写入。不会清理旧实验。
