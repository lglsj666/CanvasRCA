# RQ4.3 主张与比较对应表

本表解释当前计划的结论边界，不增加实验臂、调用或检验族。具体定义以最新主计划及技术合同为准；未执行的比较没有结果。

| 可能的结论 | 所需证据 | 不能据此声称 |
|---|---|---|
| 预选完整方法推进了纯视觉性能／成本 | X_SRP 对 U、T_FULL 的排名、完整分母和全部部署成本；历史兼容性标识；条件独立验证另判 | 历史混合 .5054 是纯视觉成绩；开发集最高分等于完成项目 |
| 完整来源包的选择优于同预算哈希选择 | 三个 S 对 C_SOURCE_HASH；同保护、包闭合、成本规则及实际干预资格 | 相同最终证据的纯表示收益；所有重要证据均被保留 |
| 新 R 系统更好 | R 对 C_READ_GUIDE，字体／编码／布局／mask 改变分别记账 | 单独证明增大字体、horizon 或网格对齐导致收益 |
| 成功 R 图依赖网格相位 | R_PATCH_PACK 对 C_PACK_OFFSET，保留同画布、内容、字体和相对结构 | 完全不改变视觉特征或 token 支持的纯因素实验 |
| 释放名额分给观测位置有价值 | R_PATCH_PACK 对 C_PACK_BG_FILL，同 PNG、K、锚点和共同基础位置 | 背景特征绝对无信息；该比较证明 attention 的因果使用 |
| 局部补充分支中的反向计算有价值 | P_LOCAL_BI 对 C_LOCAL_FORWARD；原生路径和局部来源相同 | 两者实际计算成本完全相等；反向模型扫描代表遥测因果反演 |
| 来源边界比普通双向补充有价值 | P_LOCAL_BI 对 C_GLOBAL_BI；相同合格集合及公式 | 不同组长／调度的耗时相等；特征只包含本来源信息 |
| 正确来源分组优于错误分组 | P_LOCAL_BI 对固定 C_SHAM_BI，实际分组变化达标 | 只要注意力集中便证明模型正确使用该来源 |
| S/R/P 有超出相加的交互 | 四个登记线性对比，全部因子资格与历史 U 兼容性成立 | 将单臂最高分相加得到组合性能；当前栈偏移自动相消 |
| 读取改善但没有对应排名改善 | 固定题集端到端 QA、目标覆盖、条件读取及配对 RR 分别报告 | 不显著相关证明两者独立；删掉题目目标等于模型看错 |
| 序列位置扰动超过重复噪声 | 同 60 例 U/P 的顺序、原输入及独立重复；身份兼容性资格 | 任何首选翻转都是性能下降；干预只影响 GDN 而不影响短卷积等 |
| 当前工程成本达到预算 | 三数据集分别的实际总 token 和同栈连续冷时延门槛；小样本限制披露 | token 减半等于整体耗时减半；每集 4 例证明总体尾时延 |

完整方法有工程收益而某项归因未建立时，分别报告，不能一概写成“没有成果”。反之，局部 QA 或机制显著不能替代完整方法的 MRR、成本和适用性。
