## 1. 主线与候选贡献

**主线：提高单调用、纯视觉 RCA 的 MRR，同时保持或降低实际部署成本，最终超过强文本。**

本轮围绕一个连贯问题：**有限视觉 token 中，怎样让值得保留的完整证据、可读的图元绑定和有效的上下文处理共同发挥作用？** 三个环节分别回答“给模型看什么”“怎样画”“模型怎样处理”；预先指定组合，检验它们是否兼容，而不是跑完再任意拼接最高分。

保留当前最强纯视觉 `A_UNIFORM_E50` 的工程基础。它的历史整体 MRR 为 **0.3517**；强文本 `T_FULL` 为 **0.4846**，历史混合 `MARGINAL_FIVE` 为 **0.5054**。三者结果全部复用，不安排整批同期重跑。当前成绩不是纯视觉已经达到 0.50。

来源：[RQ4.1](../experiment_reports/RQ4_1_Qwen_Analysis_2026-10-09.md)、[RQ4.2](../experiment_reports/RQ4_2_Qwen_Analysis_2026-10-10.md)、[RQ3.16](../experiment_reports/RQ3_16_Qwen_Analysis_2026-10-03.md)。历史系统／时段差异及开发数据曝光仍须披露。

本版不要求九项操作各自都是新算法。候选技术贡献集中在两处：

- **利用真实 processor 网格压缩必保留图元的 token 占用**，将预算释放给观测图元；不是缩字号、删单位或改写数字。
- **在冻结混合递归 VLM 中补充来源内的双向视觉上下文**，保留原生全局路径。

完整证据包的选择与分层色带编码提供有依据的优化方向及对照。只有相应结果成立，才讨论组合贡献；不声称新发明了摘要选择、horizon graph 或双向计算。

## 3. 共同基础与三种比较边界

沿用 220 个已暴露开发病例，AIOPS-2022／2025 各 60、AegisLab 100；候选和评分口径不变。新代码只从 `scorer` 导入评分。保持既有本地模型、排名解码、纯视觉诊断证据和单次 RCA 调用。

定义每例历史 U 的保留视觉 token 数为 `K_i`、原始编码 token 数为 `N_i`。所有新方法以 **保留 token≤K_i、编码 token≤N_i** 为输入预算，完整实际成本另测；不通过提高 processor 像素上限过关。新图严格绑定实际 processor 几何，画布仍不超过 8192×8192。

除显式编码读法外，不增加新的 RCA 策略提示。所有病例实体、数字、统计、日志和关系只在统一 renderer 图片中。无图时不能转文本诊断。

| 方向 | 保持什么 | 改变什么 | 允许的解释 |
|---|---|---|---|
| S：选择 | 可选公共证据池、候选、基本组件、解码 | 实际展示的完整来源包 | 选择系统收益，不能称同事实表示收益 |
| R：画法 | 全部公共来源记录、数值、候选和原生模型 | 图形编码、位置及其对应 token mask | 同来源事实的视觉系统收益；不假装像素、特征和 mask 不变 |

**仅 S 条件允许主动省略已登记的可选证据包。** 这与旧稿“所有条件完整保留”不同，是此次扩大证据选择范围的明确修订。选择必须记录留存／省略清单；候选目录不缩减，不能称其包含完整事实。R 和 P 不能借此默默删事实。

### 4.1 S：完整来源包，而不是又一个异常 Top-k

选择池仅来自冻结公共账本，不能回到原始私有库寻找有利记录。单位包括整条指标序列及其已有统计、完整操作记录、完整日志模板记录、完整请求配对；多实体记录必须保留全部端点。缺失值、数值写法、来源次数及单位不改，不截断单条数值数组。

所有 S 条件保留完整候选目录、公共窗口和关系账本。另设同一保护集合：对每个有记录的候选实体和每个可用 M/R/L 模态保留至少一份完整包，按稳定来源 ID 选择；已有 node／pod 资源类别也保留至少一份。类别仅由公开类型和冻结字段映射决定，不能由根因标签决定。多组共用一个包只计一次。非候选公共实体仍可被选择。

可选包的统一预算为：保护集合之外原有包成本的 **60%**。成本按原 U 图中各来源包的真实处理后包围区域计算；是固定的选择资源单位，不冒充实际 LLM token。保护包另外完整保留，不能因比例不够而删 node 证据。60% 是本轮初稿的工程取值，不是历史最优；不扫描更多比例。

先固定所有候选的原位置，再选择保留项；删除项区域留无标注背景、不画空面板或缺失警告、不重新放大其他卡片。这样 S 组内不会顺便引入新排版。实际图像 token 和保留 token 单独审核；共同使用原均匀空间分配规则，并保护被展示包的身份／单位／阶段。

**DISTINGUISH 的目标。** 只比较相同实体类型、信号／数量种类、原单位与阶段定义的记录，不比较 inclusive 与 exclusive latency。由两阶段公共分位数差构造有符号变化描述，按同类公共记录内的秩归一化。每个同口径实体对的差异权重来自描述距离；权重按比较类别、实体对归一化，防止大量重复记录主导。只有比较双方完整入选才得到该对的收益；单独呈现一个极端值不算完成比较。原始观测不改写成异常分数。对不存在共同口径的记录不强造比较，不把无记录当正常值。

**REPRESENT 的目标。** 在相同种类／单位／阶段的记录组内，用 reference/current 的公共分位数、已有计数和可对齐观测的描述计算相似度，最大化 `Σ_j w_j max_{u∈S} sim(j,u)`。稀有类别和无法比较的记录形成独立单元；不得用一个实体的曲线代替另一个实体的数值。此目标只选择哪些原包进入图，不把原型当新观测写回。归一化权重按实体及模态平衡，不能让高频日志数量吞掉资源证据预算。

**JOINT 的目标。** 两目标分别用完整公共池的理论上界归一化到 [0,1] 后固定等权相加。贪心枚举单包及合法双方包，按实际新增包成本计算增益；稳定来源 ID 打破并列。不宣称全局最优或套用并不成立的次模近似保证。对零增益、无可比配对及预算碎片，使用同一固定哈希整包补齐规则；补齐只能在既定预算内。

这比旧形状多样性或实体轮转的改动在于：完整来源包／双方闭合、统一公共 pool、原生单位的行为描述、实际渲染成本、候选与资源保护，而不是把旧分数加个系数。**如果 CPU 显示最终集合仍近似旧选择，取消而不凭概念差别强行运行。** 精确描述、权重、闭包、成本重叠及伪代码已在技术合同A冻结，未知结构显式失败。

### 4.2 R：利用图像与 token 网格的结构

**PATCH_PACK。** RQ4.1 E50 条件中，必保留锚点约占保留 token 的 86%–90%。因此直接针对“锚点占满预算”优化编译，而不继续调整已接近饱和的覆盖代理。

用实际 resize、patch 和 merger 网格计算身份、单位、阶段、刻度及必要字符串的前景支持。在原卡片内重排完整标签块与标记，减少锚点 token 并集面积；有证据归属关系的标签不能移到远端总表。优化顺序固定为：合法且不遮挡 → 锚点 token 数 → 标签到图元距离 → 稳定几何顺序。候选目录原顺序保持不变，源记录不合并，数字不改写，重复源事实不能通过去重丢失。

释放的槽位由原均匀分配规则用于观测图元，逐例总 K 不增加。分配器记录同一确定性优先序中“沿用原非锚点名额”与“锚点压缩后增加的名额”，使下文 C_PACK_BG_FILL 能审计实际重分配。这个分层记账不改变原均匀规则的最终选择。新图的目标是实际处理后诊断文字≥18px、线条≥1.5px；无法做到就登记不适用，不通过放大 processor 上限或删除值标签通过。固定网格对齐也可能加重局部拥挤或共享 token 歧义，必须检查而不是只看锚点减少。

**HORIZON。** 指标时间序列改用分层色带；Trace、日志、关系及其全部原字段保留。新R图统一18px处理后最低诊断字体，故其他组件的字体也可能增大，保留mask随之变化。R−C_READ_GUIDE只解释“可读性＋编码／布局＋token分配”的系统收益，不单独证明horizon或字号效果；本轮不增加字体匹配臂。采用固定两层色带，以零为基准、正负用不同色系、层级用固定亮度表示，时间坐标保留原值。带宽按覆盖全部观测的 1/2/5×10^k 刻度确定，显示带宽和原单位；不裁极值、不按幅度再选指标、不将分层变为数值舍入。阶段仍由原窗口位置及标签说明，不与正负颜色混淆。

缺测处按既有要求连接可用点，连接不生成新样本；不得标记缺测。所有原有精确数值字段及实体绑定继续在图中保留，不承诺单凭有限像素精确逆推出全部样本。目标是测试不同编码，而不是声称人类感知实验已经证明 VLM 能读这种图。

[Sizing the Horizon，CHI 2009](https://idl.uw.edu/papers/horizon)提供分层与图形尺寸的设计依据，也报告叠层有读取代价。这里仅借鉴编码，不继承其人类受试者结论。预计需新增 `metric.horizon`；仅在注册库确认缺口后添加，不改旧 `metric.line` 语义。

**PACK_HORIZON。** 使用相同两层编码，再执行同一网格感知排布；不另调颜色、层数或字号。不是在结果出来后选择最好的组合。

所有新图仍通过 `src/renderer/`。几何／布局／外观操作优先复用；必要新增操作仅显式启用，必须登记字段绑定、真实 DOM 几何及历史兼容性。

### 4.3 P：保留初稿的实质计算假设，移出 ECHO

`P_LOCAL_BI` 继承旧稿的语言层 0–2、λ=0.25：保持原生路径，在唯一来源支持的视觉位置增加前向／反向局部扫描，按 `(1−λ)o_native+λ(o_forward+o_reverse)/2` 融合。共享来源 token 走原路径，局部状态不写入生成缓存；文本与答案生成仍为原生因果处理。

`P_SOFT_IMAGE` 在语言第 3 层（首个 full-attention 层）对视觉 query 混合原输出与图内双向输出，λ 同为 0.25。它是受 [SoFA](https://arxiv.org/html/2503.13792)启发的单图输出混合适配，不冒充原论文 mask 混合算法复现。

`P_DUAL` 串接这两项已固定操作，不增加生成次数。SOFT两路各自仅按允许key做原attention softmax，在原sigmoid输出gate和o_proj之前按λ混合，不添加向量归一化。SHAM的哈希成员分配、跨层固定映射及FORWARD融合公式见技术合同C4。两条路径都可能有训练分布偏移，必须做独立小张量、真实缓存与增量解码核验。反向计算不反转遥测时间，不能解释成对因果传播的反演。算法公式沿用旧稿§3，安装栈、shape、反向gate索引、padding、缓存和顺序置换以技术合同C为准；旧稿主矩阵不适用。

## 5. 其他条件：七个控制与四个预先指定组合

### 5.1 七个必要控制

| Arm | 目的 |
|---|---|
| **C_SOURCE_HASH** | 相同保护集合、整包规则和预算，按固定哈希选择可选包；区分选择准则与“少给一些证据” |
| **C_PACK_OFFSET** | 同一 PATCH_PACK 设计，对整块内容施加固定半个 merger 单元的网格相位偏移；保持画布／完整内容，检验收益是否依赖 patch 对齐 |
| **C_READ_GUIDE** | U 原图与计算＋R 组共用的静态编码说明，检查新增读图说明自身的影响 |
| **C_LOCAL_FORWARD** | BI 相同来源、λ和层，只保留局部前向补充，区分局部处理与反向信息 |
| **C_SHAM_BI** | BI 相同组大小与计算，按固定种子重排局部来源归属，检验正确来源对应 |
| **C_PACK_BG_FILL** | R_PATCH_PACK 同图、同保留 token 数，将压缩锚点后增加的名额分给真实背景位置而非新增观测位置；检验释放预算的使用价值 |
| **C_GLOBAL_BI** | 与 P_LOCAL_BI 相同层、λ、向量和双向公式，将相同合格 token 作为一个组处理；检验来源边界是否优于普通双向补充 |

OFFSET 必须在设计时预留边界，不能通过裁图或循环环绕移位制造伪证据；字号、相对图元距离和文字不变。若不能做到同画布完整平移，取消该控制并限制“patch 对齐”归因。即使保持源事实，位置偏移仍会改变视觉编码，不能叫纯 token 数效应。

R 组与包含 R 的组合统一使用一份“若出现该编码”的静态说明；C_READ_GUIDE 使用相同说明。S、P 继续使用原任务。故跨方向 R 因子包含必要读图说明；R−C_READ_GUIDE 才更接近图形系统差别。

**新增控制一：预算释放与布局本身。** C_PACK_OFFSET 改变位置、特征及可能的 token 支持，不能单独说明 PATCH_PACK 是否通过新增观测名额起作用。C_PACK_BG_FILL 使用 R_PATCH_PACK 完全相同的 PNG、processor、视觉编码、提示、模型和解码，保留全部同样的锚点。

设 R 的实际保留数量为 `K_R`，其中锚点数量为 `A_R`；历史 U 的非锚点数量为 `Q_U`。按原均匀优先序固定前 `min(Q_U, K_R−A_R)` 个非锚点位置为共同基础，其后的 `D=K_R−A_R−min(Q_U, K_R−A_R)` 个位置为新增名额。R 按原规则使用它们；控制仅将这 D 个位置替换为同一图像中、原未保留且不与任何诊断前景相交的真实背景位置，固定哈希选择，无放回，并恢复正常序列顺序及原空间坐标。两者保留数量相同，共同位置的特征和空间坐标相同；完整 PNG 中的来源事实均保留。审计新增名额中实际覆盖观测图元的比例，不能将所有非锚点 token 都称为观测。

背景位置不足、D=0 或新增位置没有观测覆盖时登记不适用；不得生成零向量、复制 token、扩图或改像素上限补足。每集至少50%病例存在有观测覆盖的合法替换才保留此控制；其余未触发病例引用实际相同请求并留在分母。几何背景特征已经可能混入全局图像信息，替换还改变语言序列组成，因此比较只支持“新增名额分给观测位置相对背景位置”的系统效果，不能称背景是绝对无信息或证明单一 attention 因果机制。这个控制不是部署候选，不改变主方法对 U、T_FULL 的强基线比较。

**新增控制二：来源边界与普通双向处理。** C_SHAM_BI 保持组长却错误分组，C_LOCAL_FORWARD 删除反向支路；二者仍不足以排除“不分来源的双向补充就足够”。C_GLOBAL_BI 在同一语言层0–2，以相同λ=0.25、同样原生投影／短卷积后的向量和融合公式，对 P_LOCAL_BI 的同一合格 token 集合按原序列顺序执行单组零初态前向／反向扫描。共享／全局等原本不合格位置不加入新分支，文本和原生缓存规则保持不变。

唯一算法因素是局部分支在每个真实来源边界重置，还是在全部合格位置合成的一组内扫描；该因素也会改变上下文长度和内核调度，不能声称实测耗时完全相等。它与 P_SOFT_IMAGE 不重复：后者修改 full-attention 路径，本控制与 P_LOCAL_BI 使用相同 Gated DeltaNet 路径。资格须核对合格集合完全一致、边界确有变化以及真实缓存安全；无边界差别则引用相同计算，不重复生成。

### 5.2 固定一个 2×2×2 组合，不做 3×3×3 穷举

预先取 **S=S_JOINT、R=R_PATCH_PACK、P=P_LOCAL_BI**；U、S、R、P 已在历史或九臂中，补四个组合：

| Arm | 内容 |
|---|---|
| X_SR | S＋R |
| X_SP | S＋P |
| X_RP | R＋P |
| **X_SRP** | **S＋R＋P；本版预选完整候选** |

S 永远基于原始公共池和原 U 的固定包成本选择，不能因 R 改布局再偷偷改选择；P 基于实际已渲染来源映射。这样可检验选择、画法、处理的交互，而不是把三个独立臂的最高分相加当作组合成绩。

X_SRP 是本版在任何新结果前指定的候选，不是后验赢家。其技术可能性尚待资格审查；若某因素失败，取消依赖它的组合，不自动替换成该方向的其他臂。

## 6. 机制：保留 QA 脱节与顺序敏感性

固定哈希取 60 例，每数据集 20 例，优先不同事件组；不按新旧排名选。

- **九条件 QA：** U、S_DISTINGUISH、S_REPRESENT、R_PATCH_PACK、R_HORIZON、P_LOCAL_BI、X_SRP、C_PACK_BG_FILL、C_GLOBAL_BI，每例每条件一次，共 540 次。新增两条件沿用同一60例、同一题目及答案标准，检验两项控制差异是否也出现在读取／绑定上。沿用独立 QA 接口，每例最多六题，明确包含指标标签、指标图形读数比较、Trace/日志以及关系，精确定义与NA规则见技术合同E。
- **两条件顺序干预：** U 与 P_LOCAL_BI，各 60 次，共 120 次。原像素、视觉特征、保留集合及空间坐标不变，只改变语言侧来源块串行顺序，沿用旧稿的边界。
- **独立重复：** U与P_LOCAL_BI各覆盖同一60机制例，给顺序干预提供配对噪声对照；R_PATCH_PACK与X_SRP仍各12例（每集4）。共144次，不把重复当独立事件样本。后两者只检查粗略稳定性。
- **当前栈计时：** 上述每集4例的U/X重复兼任冷路径计时，另给T_FULL新增12次同配置计时。历史220例准确率仍直接复用。

QA 题目从完整公共池按同一规则固定，S 可能不再展示部分目标。必须分别报告：目标可见覆盖率、固定题集的端到端可回答准确率、各条件共同可见目标上的读取准确率。未展示在端到端主分数计0，错误类型记为证据不可得，而非模型看错；不能从完整题分母中删除。诚实unavailable单独报告，不当读数正确。8项QA检验都使用这项固定pool端到端分数，共同可见目标准确率仅作描述。允许 QA 返回 `unavailable`，但不给答案卡；QA 的任何结果都不进入 RCA。

这可以区分“选择删掉了可回答信息”“保留信息读得更好”以及“上述变化是否转化为排名收益”。不以多道题增加独立样本数，不以 QA 提升代替方法成功。

Attention 只复用固定子集真实调用，继续包含静态文本与图像区域，每调用≤64 KiB，含索引、临时与分配空间每万次≤十进制 1 GB；不保存完整矩阵。局部分支只记聚合范数／数量／耗时，不把一个 full-attention 层的测量冒充 GDN 状态解释。

## 8. 资格、统计与时间成本

### 8.1 先做不花模型调用的筛除

1. **历史和内部去重。** S 比较实际来源集合及字段覆盖；R 比较真实处理后图片和锚点／观测支持；P 比较实际计算和输出增量。不能只看函数名。
2. **S 适用性。** 保护集合完整，真正发生来源选择；按每数据集全分母报告。若三个 S 选择几乎相同（两两集合 Jaccard>0.95 的病例达到某数据集 80%），先合并／取消重复条件；不通过微调权重强迫差异。至少每数据集 50% 病例有可变化的合法选择，才保留该候选完整资格。
3. **R 实质性。** PATCH_PACK 的拟议门槛为每数据集至少 50% 病例锚点 token 数减少≥10%，且没有文字、单位或来源丢失。若只是换位置而没有释放预算，不跑其整批 RCA。HORIZON 须实际替换合格指标编码、保留完整样本绑定，不能用大部分原图回退冒充新编码。
4. **P 资格。** 沿用旧稿来源覆盖、独立算子、λ=0、缓存及文本因果性检查；SHAM 需要实际改变局部组关系。失败只阻断依赖它的臂，不让三个研究方向相互无谓阻塞。
5. **成本和可读性。** 所有请求输入＋8192≤40960；有限布局候选及硬字号资格按技术合同B；新 R 图不通过缩字体、删值或提高像素上限过关。所选原包无丢字段；帧边界、零值、极值、长名称、共享支持、缺测跨线全部核验。

以上是初稿可行性门槛，不是模型效果门槛。若不通过，记录真实失败；任何科学条件修订必须在首次新调用前另行版本化，不能边跑边放宽。

### 8.2 图像预算不足与共同回退

对不适用的S、R、P先区分未触发、合法策略回退与资格错误，按技术合同D逐项指定实际等价请求，不能统一引用U。例如D=0的背景控制引用R；带R读图说明的旧图等于C_READ_GUIDE而非U。只有像素、文字、seed、保留集合及计算身份完全一致才能引用；否则作为其登记位置正常单调用。各条件保留完整分母与回退率。坏图、漏事实、未知结构不能靠回退掩盖；每方向每集有效干预不足50%则取消该候选，停止其依赖组合。

### 8.4 预注册比较与采用边界

**主要方法族：** X_SRP−U、X_SRP−T_FULL，两项 Holm；事件组推断为主，病例分析另报。主目标是超过强文本；相对 U 的 +0.03 及逐数据集不退化只算开发进步。X_SRP 不能因其他臂更高而事后改名。

**优化探索族：** 九个优化臂各对 U，共九项 Holm，所有绝对 MRR 和成本都报告，最高点估计仅称探索结果。

**归因族：** 三个 S 各对 C_SOURCE_HASH；R_PATCH_PACK−C_PACK_OFFSET；三个 R 各对 C_READ_GUIDE；P_LOCAL_BI−C_LOCAL_FORWARD、P_LOCAL_BI−C_SHAM_BI；新增 R_PATCH_PACK−C_PACK_BG_FILL、P_LOCAL_BI−C_GLOBAL_BI，共十一项，使用同一Holm族。涉及 R 的结论含重编码与token分配变化；S 不声称同事实视觉收益。

**跨方向交互族：** `SR−S−R+U`、`SP−S−P+U`、`RP−R−P+U`、`SRP−SR−SP−RP+S+R+P−U`，四项。只在对应交互有支持时称非加性协同。组内双操作组合也可以描述，但没有预注册支持就不宣称其协同已证明。

历史依赖不兼容或未证明可比时，所有含历史U的优化／交互／顺序对base等科学推断按合同D2失去资格，p=1占位，保留带版本局限的历史系统描述；不能将当前栈偏移写成协同。少数重复相同不证明所有输入兼容；不自动重跑220基线。当代对当代有效对照仍可分析。

技术合同F固定全部统计：主要2、优化9、归因11、交互4、机制12项各自Holm，病例与事件组分开；事件组为193，病例平均、组平均与宏平均同时报告。双侧Pratt、12位差值、配对dz、zeros/ties与常量规则明确；不报告CI。signed-rank位置检验不冒充任意均值检验。机制包含实际指标图形QA和同60例噪声配对，不能把题目／token当独立病例。完整输出MRR、AC@1/3/5、Precision、AVG、修复／破坏和未知界限。 各Holm族分别控制其对应问题，不声称全部研究的总体错误率只有5%。报告每个arm×数据集的有效干预、精确引用、策略回退、资格失败与unknown比例，紧邻MRR／成本表呈现；不得用大量回退后的总体分数冒充新操作普遍生效。选择器另报保护闭包、可比闭包、singleton、实际目标增益及哈希补齐份额。完整质量—成本结果和失败因素均保留，不只展示赢家。

完整成本按技术合同G连续计时，包含原始编码、选择、绘图、token操作、prefill、生成及验证。部署入口固定为每集input+output均≤1.05×U和T；冷时延分别在每集同四例计算mean(X)/mean(U)、mean(X)/mean(T)，都须≤1.05；不能用合并12例均值替代；无OOM／未解决unknown。每集仅4计时例限制必须披露，不能称精确总体speedup。统一栈、负载和采集开关；历史wall仅为跨时期参照。

### 8.5 执行和停止边界
