## Decision and next step

Do not promote R-only, R+G or R+L+G as a universal replacement. The sharp trace
cases and IO/raft cases react differently. The next useful hypothesis is a
public evidence-strength routing rule that can suppress distractors when a
strong trace signature is present while retaining resource/raft signals when
it is not. Register that rule before calls; never use the private root to pick
a per-case image. Check metric types and scale as separate factors.

The long-answer inconsistency also motivates inspecting the structured answer
emission order: a ranking emitted before an evidence summary cannot be revised
later within the same JSON. That is a future prompt/schema-order hypothesis,
not an established cause or an authorization to alter completed answers.
