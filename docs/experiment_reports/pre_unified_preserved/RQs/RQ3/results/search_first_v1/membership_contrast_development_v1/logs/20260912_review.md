## Decision and next step

Preserve the negative batch and leave the old main lifecycle disabled. Name
binding is sometimes used correctly, but is not sufficient. The new selector
can overselect small absolute memory changes and omit informative specialized
metrics (e.g. raft wait); do not adopt broad resource-name heuristics blindly.

Next audit exact public field semantics (`rrt`, LOG-R ratios, baseline/current
units) and add a small versioned semantic-guide/scale contrast. The public
guide should not let a nearly unchanged event-rate ratio imply cessation or
equate a counter increase with capacity saturation. Verify their definitions
in source before changing any wording. Consider preserving native-ranked
anchors when testing cross-source retrieval. No private labels enter any such
guide or selector, and no validation/eval is opened for this diagnosis.
