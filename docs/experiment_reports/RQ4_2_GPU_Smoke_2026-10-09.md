## 发现、修复与保留的失败

1. **加载接口缺少可选 accelerate 依赖。** `from_pretrained(device_map='cuda')` 在当前环境启动失败，尚无请求尝试。改为CPU加载冻结BF16权重，再 `.to('cuda')`；不安装依赖、不更换模型、精度或运算后端。
2. **attention 映射哈希不能序列化 NumPy 数组。** 第一条请求生成前出错。将实际区域编号规范化为 Python 整数列表后再计算哈希；不改变区域、模型输入或 attention 数值。该尝试保守计账、保留为 interrupted，修复后以新 attempt 执行。
3. 两次修复均重新通过受影响的6项CPU检查、刷新版本凭据，在同一原始截止时间内继续。旧错误/日志/报告保存在 `startup_failure_1/`、`startup_failure_2/`，不抹去历史。
4. 后续16条完整回答没有新的运行异常。日志提示本环境缺少可选线性 attention 快速内核而使用 torch 路径；本轮没有更换实现。这是后续效率解释需披露的运行环境因素。
