# RQ4.3 v6：布局修复与分阶段 CPU 审核

2026-10-11，America/Toronto。**结论：S/P 的已实现 CPU 路径通过；R 原型仍超出保留 token 配额，完整 CPU 资格未通过。GPU smoke、正式实验均未启动，新增模型调用 0。** 本报告是实现与可行性证据，不包含新的 MRR、推理成本或方法采用结论。

## 1. 授权和本版修订

用户明确批准“允许修订布局，记录为新版方案”。[v6 计划](../experiment_plans/RQ4_3_Selection_Rendering_Processing_Plan_v6_2026-10-11.md)允许修改 R 的换行、卡片尺寸和排放，继续保留全部来源事实、原数值字符串、处理后字号 ≥18px、线宽要求、原 processor 限制和逐例 N/K 配额。v5、早期失败、历史源码和结果均保留。没有修改 Codex.md。

N 是完整视觉编码所用的图像 token 数；K 是历史 A_UNIFORM_E50 实际保留并送入语言骨干的视觉 token 数。**能放入画布、N 合格，并不表示能满足 K。** 身份、单位、阶段、刻度及必要字符串的锚点本身也占 K，不能在预算不足时删掉。

所有新图仍通过 `src/renderer/`。本次 opt-in 扩展为 `readable_cards/source_reflow_v3` 与 `anchor_pack`：前者重排完整字符串并减少留白，后者以实际 alpha 前景进行有限整数位移。图形沿用已有组件；历史默认语义保持。R 源码没有另建实验专用绘图器。

| v6 图像审核 | 220/220，0 错误；440 张 S 图 | 保留面板与历史原图逐像素相等；每个实际 processor 网格及 K/N 均审核 |
| P 历史输入重算 | 220/220 | 特征无关 UNIFORM 索引与原提交索引完全一致；输入 PNG、processor 几何保持 |
| 当前受影响静态/单测 | 静态通过，18/18 通过 | 仍不是全部实验入口已部署 |

| R 实际重绘与有限 packing | 三个预定数据集样例 | 三图渲染通过，预测/重绘锚点集合完全相同，但 K 都失败 |
| GPU smoke / 正式 / QA 模型调用 | 0 | 未授权、未启动 |

图像全量阶段用了 7 个不同物理核 worker，耗时 548.4 秒。同期小范围 R 审核使用另一物理核，合计不超过 8。模型网络连接禁用，未加载预训练权重。实际 processor 在 CPU 执行，不是估算图像 token。源数据、Codex 和阶段保护的历史依赖在运行期间未变。

原全量阶段使用冻结通用提示计数；随后发现 S 条件不应声称展示“完整”遥测。现登记仅两项表示中性的措辞替换：`the complete telemetry dashboard` → `the available telemetry dashboard`；`All incident observations` → `The displayed observations`。候选目录仍明确 exhaustive，其他读图、排序、输出要求完全不动。P 保留原提示。220 例重新核对提示及输入计数，每数据集两种 S 条件各用真实多模态 processor 复核一例，共 6 次，与全体重算一致；此修正没有改变文本 token 数。旧阶段不覆盖，新凭据保存在 followup01。

此外修复了空支持兼容路径的审计记录：只有像素、位置和 processor 相同的既有非空来源支持可以引用；空历史支持不能用空集包含关系冒充已覆盖。440 个已提交 S 输入均无未解决空支持，不需为该防御性修复重画全部图。

## 3. 选择方向去重和输入预算

按预注册规则，任一数据集至少 80% 病例的来源集合 Jaccard >0.95 即触发近似重复检查：

| 条件对 | AIOPS-2022 | AIOPS-2025 | AegisLab | 处理 |
|---|---:|---:|---:|---|
| S_DISTINGUISH / C_SOURCE_HASH | 52/60 | 59/60 | 75/100 | 保留哈希对照，取消 S_DISTINGUISH 独立调用 |
| S_REPRESENT / S_JOINT | 59/60 | 57/60 | 57/100 | 保留预选 S_JOINT，取消 S_REPRESENT 独立调用 |

这些是近似重复，不是假定同输入，因此不能把近似回答作为精确引用。固定统计位置记 `preregistered_redundancy_cancelled`、p=1；不能解释为测得零效应。AegisLab 局部差异保留，不事后增设仅该数据集的条件。

当前分配从 6,548 减少 560 个方法/QA 位置至 **5,988**。8,000 是总空间，不是本轮必须用满的数量；5988 仍为含条件模块的计划上限，并非已具备资格的队列。

下表为剪枝后模型输入 token（含静态文本），不含输出、编译、视觉编码与额外 P 分支计算：

| 数据集 | 历史 U / 当前 P 同输入 | S_JOINT | 相对下降 | C_SOURCE_HASH | 相对下降 |
|---|---:|---:|---:|---:|---:|
| AIOPS-2022 | 5765.52 | 5114.28 | 11.30% | 5140.17 | 10.85% |
| AIOPS-2025 | 5234.27 | 4444.33 | 15.09% | 4452.67 | 14.93% |
| AegisLab | 5816.87 | 4870.97 | 16.26% | 4898.01 | 15.80% |

所有 S 输入均未超过原 K。全图 token 未超过原 N；完整图像输入最大 16,777，加 8192 输出仍低于 40,960。留白保留原尺寸，因此不能把剪枝后输入节省称为免除了完整视觉编码。选择删掉的是登记允许的可选完整包，必要保护集合、候选、关系和显示包内的源记录均保留；这也不是同事实表示实验。

P 的来源单元资格为 60/60、60/60、100/100。X_SP 在已选择的真实 S_JOINT 图上重新绑定，也为 60/60、60/60、100/100；覆盖比例最低分别为 72.14%、79.88%、57.69%，超过登记 20% 必要门槛。**来源几何可归属不等于已编码特征没有全局混合，也不等于计算分支已被实际模型资格验证。**

## 4. R 修复了什么，为什么仍不通过

完整字符串的原 readable profile 在三例中分别需要 20,032/17,504/19,584 个图像 token，超原 N。v6 使用真实 DOM 高度、稳定整卡放置、紧凑间距及 512/1024 混合宽度，修复了窄列关系图的空白和高度浪费；图关系仍完整。中间发现的 SVG 轴标签/节点图测量不一致已修复，失败原型保存在 probe01–probe06。

最终三例 source 图与 processor 输出同尺寸，没有缩放，诊断文字约为 18px（DOM 浮点最低 17.999951px）。有限 packing 只移动完整标签块，不移动拓扑标签或共享像素；重绘 alpha 支持与预测集合完全一致：

| 数据集 / 固定例 | 画布 | 完整图像 N | packing 前锚点 | packing 后锚点 | 原 K | 后锚点超 K |
|---|---|---:|---:|---:|---:|---:|
| AIOPS-2022 / INC-5A5C12F46667 | 4096×3968 | 15872 | 7823 | 7306 | 5332 | 1974（37.02%） |
| AIOPS-2025 / INC-6DCAE95A54B2 | 4096×3424 | 13696 | 6402 | 5895 | 4784 | 1111（23.22%） |
| AegisLab / INC-E92A6FFD9DC0 | 4096×3936 | 15744 | 7766 | 7206 | 5444 | 1762（32.37%） |

锚点分别下降约 6.61%、7.92%、7.21%，但**尚未给任何非锚点观测图元分配名额就已超 K**。因此不能称原型通过 R 的预算门槛，也不能靠缩字号、丢标签、修改 processor 限制或扩大 K 继续。

这些是三个固定例的原型失败，**不是对 220 例 R 适用率的全量结论，也不是所有可能布局都不可行的证明**。当前停在计划规定的小范围可行性步骤，不浪费算力生成注定无法由此版本获得资格的后续模型请求。HORIZON 及依赖 R 的组合尚未实施完整资格，不能用其尚未测量的收益为此门槛背书。

## 6. 下一步和停止边界

本轮代码与已启动审核都已结束，没有残留自有 CPU/GPU 实验进程。完整 CPU 尚缺：

1. R 在不改事实、字号和 K/N 的条件下建立可行原型，之后才能做全体资格与 R 控制/组合；否则按登记处理该方向，不以放宽门槛冒充修复。
2. 全部存活条件的 QA、顺序扰动和最终输入编译。
3. 正式运行器、原子提交/暂停排空/快速恢复、精确引用与真实重复的集成回归。
4. 完整历史生成兼容审计及后续受控 GPU 资格。

不因 S/P 部分通过自动转为 GPU 就绪，不自动重新定义预选方法。**当前状态为 partial_cpu_passed_R_prototype_budget_blocked。** 用户的停止边界仍为 CPU 后停止；本次没有 GPU smoke 或正式调用。
