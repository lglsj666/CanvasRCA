## 实施内容

- 四个主臂：FULL_TEXT、COMPACT_TEXT、ADD_VISUAL、REPLACE_VISUAL，各 220 例。
- 在固定哈希选择的 60 例上执行 C/V 独立重复，共 120 个位置。
- 同一 60 例执行八种 QA/正确读数干预接口，共 480 个位置；QA 独立会话，模型回答不回填 RCA。
- 合计 1,480 个正式位置；无配对病例保持完整文本，18 个完全相同的普通请求位置可引用本轮结果，重复臂始终新调用。
- 配置默认关闭执行，以当前源码、配置和登记哈希绑定的用户授权凭据激活。条件 attention、SIRCL 和扩展验证未加入本次队列，保留各自闸门；总资源上限 3,000，不等于立即启动 3,000 次调用。

完整 M/R/L/G、候选及配对事实保留。紧凑文本采用可无损恢复的具名列表示；视觉替换仅移交实际图中可恢复的字段。图中舍入后无法恢复精确值的数值仍留在文本。父/子实体、操作和总体数量从正文移交，避免只删除重复摘要却声称完成替换。

全部 PNG 来自最新 `src/renderer/` 的已注册 `trace_profile.quantiles`；未增加或修改 renderer。复用旧 PNG 前验证当前共享源码及 bundle 一致，三例实际重新绘图后字节一致。

## 发现并修复的问题

1. 第一版每字段重复图片指针导致 AIOPS-2025 的 V/C 输入比 1.051530504，未通过 1.05。失败输入、日志和源码保留在 v1。v2 改为一次性字段映射说明，保持事实、图、臂、阈值不变；完整 CPU 重跑通过。
2. GPU 前把 QA 单位评分改为接受 `ms` / `millisecond` / `milliseconds` 的等义写法，仅规范单位/耗时类型的大小写及外侧空白；秒、exclusive 仍错误。随后完整 CPU 再通过，用时 250.64 秒，未基于模型结果调整。
3. GPU 后的产物审核错误地要求 `rank` 总为数值，而合法前五未命中为 `rank=null`。只修正 `review_smoke` 的数值字段检查。AST/源码证明其它逻辑、输入、renderer、配方及评分器均不变；5 个错误数值/排名负例被拒绝，18 份真实产物重新审核通过。原冻结、凭据、源码和失败记录保留，新增模型调用为 0。当前 CPU/视觉资格通过明确的兼容证明衔接此纯审核修订，未伪称修订后重跑完整 GPU。

4. 首次正式启动时后台监督进程未能持续存活，已加载的自有模型服务成为孤立进程，尚无正式请求。保存状态后关闭该自有进程组，改以独立 OS session 托管同一冻结运行脚本；不修改实验代码或配方。具体外部终止原因未证实，以进程存活、真实队列和首批原子提交作为最终启动证据。
