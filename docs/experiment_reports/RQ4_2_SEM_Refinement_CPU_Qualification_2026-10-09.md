# RQ4.2：SEM 分组修订与 CPU 资格

2026-10-09；当前版本 `partition_v4`。**SEM 干预门槛已通过，CPU 准入检查通过；GPU smoke 未运行，正式未启动，真实模型调用 0。** 本报告不包含新的 RCA 分数、真实 checkpoint 推理或 attention 结果。

## 1. 修改了什么，为什么修改

用户在 v3 科学门槛失败后明确授权继续修改方法。本轮修改的是分组求解器，保持原有五臂与科学问题。旧算法只接受单步严格减少跨组关系的移动／交换，容易在异尺寸完整来源单元、等容量和背景移动约束下过早停止。仅增加三组交换或面积权重曾未解决问题，相关失败保留。

新版使用确定性的“交换序列＋最佳前缀回退”：每轮允许暂时零收益或负收益的步骤，已移动单元在该轮锁定；最后只提交总切边权重严格下降的最佳前缀，其余探索回滚。每个中间状态都满足原容量和背景约束。至多 8 轮、100 次提交的移动／交换，稳定 ID 打破并列，不搜索随机种子。

这种局部搜索与最佳可行解回退有图分区文献依据；这里实现的是针对本项目约束的适配，不是新发明的图分区算法，也不是 KaFFPa 的完整复现。[Sanders 与 Schulz，2011，§2.2](https://arxiv.org/html/1012.0006v3)中的原实验不是 RCA，也不证明本方法会提高 MRR。旧 KL 论文仅核验了元数据与摘要，未获取全文，未将其未读细节作为实现证明。

没有修改：220 例分母、图像、来源闭包、数值、关系类型和度数归一化、原有均匀来源边权、SHAM 重连种子、20%／20%／15% 的逐例要求及每数据集 50% 的适用比例。求解器接口没有面积加权变化率或准入分数输入；它只优化原关系切边。四个固定页眉单元在新版中显式禁止移动。

## 2. 完整 220 例结果

固定 30 例探针先验证可行性，随后审核全 220 例。30 例探针和完整审核的重复计算结果完全一致，未重新选病例。

| 数据集 | v3 SEM | v4 SEM | 要求 | v4 SHAM |
|---|---:|---:|---:|---:|
| AIOPS-2022 | 50/60 | **57/60** | ≥30/60 | 56/60 |
| AIOPS-2025 | 55/60 | **56/60** | ≥30/60 | 56/60 |
| AegisLab | 38/100 | **71/100** | ≥50/100 | 90/100 |

三个数据集分别通过，SHAM 保留。没有把多个方法各自成功病例取并集。

AegisLab 前景面积加权同组变化率中位数从 **18.64% 提高至 24.02%**，真实关系切边降幅中位数从 **59.90% 提高至 63.76%**。68/100 例的新分组提交序列包含至少一个暂时非正收益步骤，说明单步改善限制确实会排除这类协调交换；这仍不是对 RCA 收益的因果证明。

逐例独立复算最终切边、两种同组变化率、四组等容量、来源闭包、固定页眉与背景移动；全部符合原约束。合成屏障案例中，旧局部算法切边为 11，新算法为 7，且总收益来自包含非正收益步骤的严格改善前缀。

## 3. CPU 检查及复用范围

- 静态检查通过：五功能模块 1,764 行，111 项受保护文件摘要未变，未修改 `Codex.md`。CPU 资格绑定 100 项源代码／配置依赖。
- 共享 renderer 源码与 v3 冻结版本一致。复用此前 220/220 来源装箱、实际渲染、404,452 个绑定核查、原生区域像素相等与历史默认 PNG 兼容检查；没有重复渲染整批主图。
- 当前 RQ 回归 **27 项通过、1 项兼容的既有浏览器检查复用**。随后针对门槛防篡改、GPU 入口关闭和中断账本，3 项检查通过，其中 1 项与前套件重复，不能重复计为新测试。额外 2 项新测试使本轮不同通过项为 29。
- QA 固定 60 例：59 例图像通过，1 例不足两个合格阶段记录，按登记不适用；共 350 个适用问题，生成输入无原始根因标签或历史答案。QA 不继承 RCA 排名指令，答案不进入 RCA。
- 实际 processor 在 CPU 上检查 **220 例、558 种不同处理形式**：220×主图／四图，加 59×QA 主图／四图。同一 PNG 的 FULL/GEOM/SEM/SHAM 共享处理结果，编码器分组另外验证。没有加载模型权重或使用 GPU。
- 全部图像保持原尺寸，无 processor 缩放。最大图像 token **16,384**；最大完整输入 **16,846**，加输出上限 8,192 为 **25,038≤40,960**。不能据此宣称实际总成本或时延下降。
- 五种臂的冷编译／实际 renderer／输入身份校验／离线提供器／评分及提交路径检查通过，覆盖三个数据集、RCA、QA 和 NATIVE4。重新编译输入身份与登记相同，完成标记恢复在物化输入之前生效。5 次离线替身调用不属于模型调用，其分数不用于研究分析。
- 保留原随机权重真实 27 层视觉架构 CPU 算子检查；本轮实际运行的回归再次通过 K=1 一致、组重命名、完整 patch 与 merger 邻域、退出恢复等测试。真实 checkpoint 数值与速度仍属于未来 GPU 资格。
- attention 区域映射改为只累积图元实际相交网格，避免整幅 token×图元扫描；独立小网格复算通过。文本和图像均可记录，单调用64 KiB／每万次十进制1 GB上界保持。真实采集开销未测。

人工实际打开三数据集的新 QA 区域，核查目标颜色、下划线和实体／单位位置；另打开全 220 例中最大绝对指标观测的区域。主图、最密拓扑及长名称例图沿用上一轮已打开且像素未变的图。密集拓扑交叉和信息密度仍是限制；CPU 几何资格不等于模型已经读懂。

QA 评分在首次模型调用前固定：读数用 Decimal 精确数值相等，不允许误差；JSON 数值也按 Decimal 原精度解析，避免先转 float 造成错误扣分；实体须相同数字 ID，微秒等价 Unicode／单位拼写允许归一；关系集合须类型及方向完全匹配；阶段比较用固定类别。无效回答计零，题目不被当作独立病例扩样。
