# 跨实验画像：Qwen 的层次、故障与数据复杂度

Qwen-only 修订版：2026-09-30。原文件日期标识所分析的历史批次，并非新增实验日期。

本报告仅讨论 Qwen3.8-27B；结论由其自身病例和结果决定，不要求跨模型成立，也不推广为所有模型的性质。原始输出、分数、输入与实验状态未改；本轮新增推理调用为 0。

统计按 Qwen-only 范围重新分析：保留原科学问题的全部正负比较、病例掩码及失败处理，重新计算 Holm；有逐病例记录或差值的主比较重新复算配对检验与 dz。原始 p 在样本未变时本来就不依赖其他模型。CSV 数值往返影响浮点并列时，保留原数值并列口径，另存重算敏感性。附表 `raw_statistic_source` 明确区分重新配对计算与沿用同一 Qwen 样本的原始统计。没有把事后分析改称预注册发现。

## 范围与比较原则

整合本报告原覆盖的 RQ1.1、RQ2.1、Tournament、RQ3.1–3.5、RQ3.6-A 的 Qwen 结果。它不包含后来 RQ3.6-B 或 RQ3.7 的新结果；那些报告另行列示。唯一病例池为原 840 个 eval/test 病例，但不同阶段实际样本和共同掩码不同。

方法表现只在同阶段、同病例、同评分契约内配对。不能把某 60-case screen 的高分和另一个 360-case test 直接排冠军；跨阶段画像用于找机制线索，不当作统一排行榜。CPU 基线在其源报告单列，不混入 Qwen 总体。

## 根因层次与故障类型

X 对 node 是显著负向：RQ3.1 X-table 相对 T 的 node ΔMRR 约 −0.3268。它丢失资源线索的问题不能用“更有对比性”抵消。SC 恢复 owner 覆盖后仍未稳定恢复机制与排名。

但 X 有网络方面的正信号：network-delay 15 例 T→X-table 为约 0.1278→0.5444，packet-loss 23 例为 0.2536→0.4130，partition/bandwidth 14 例为 0.3036→0.7143；memory 59 例则 0.3969→0.2322、disk 53 例 0.3553→0.1368。全部分组检验重新在 Qwen family 校正，不能只选显著或正向的分组汇报。

SC M-text 的 memory 55 例从 T 的 0.3712 到 0.5212，Top-1 修复/破坏 16/3；RQ3.6-A S 证据在 memory 15 例却从 0.4889 到 0.1500，packet-loss 8 例从 0.5000 到 0.8125。名称相近的方法可能保留完全不同的机制字段。

## 图规模和 hop 能回答什么

公开图最大有限最短路径几乎绑定数据来源：AIOPS-2022 主要为 2，AIOPS-2025 多数为 2、部分无边，AegisLab 为 4，RE2-OB/TT 为 2/4。根因深度、节点数与应用/故障类型同时变化。因此现有结果不能独立证明“某方法擅长几 hop”。

图没有边可能是观测缺失，不自动意味着系统没有依赖。case-feature 表保留原定义、图来源和 root-entry-hop；相关性不转化为故障传播的因果证据。按 dataset 内部变化和控制 root/fault 的探索分析仍需注意缺乏重叠支持。

## Metrics 复杂度

series 中位数约为 AIOPS-2022 4,612、AIOPS-2025 937、AegisLab 1,777、RE2-OB 58、RE2-TT 334.5；有限抽样的有效秩约 21.77/21.10/7.73/17.74/28.08。列数不等于动态复杂度，也不是最终 prompt 大小。

有效秩基于有界 128-series、64-time 抽样，不是完整系统熵。缺失率、冗余、变化量分别报告；不能把 token 当 bit、把图规模当难度或把特征相关当因果机制。

## 可行动的规律

1. 区分资源/node/内存的损失与网络/操作级收益；新增覆盖必须和破坏原有能力一起核算。
2. 检查具体语义：memory usage/GC/page-fault、I/O await/吞吐/容量、请求量/错误/本地耗时不能互相替代。
3. 宿主异常不自动意味着宿主故障，peer 和局部执行需要真实可比观测。
4. 强文本、同事实图文和完整部署基线分别回答不同问题；接口收益不能冒充视觉收益。
5. 这些画像可形成少量后续假设，不可用真实根因类型或事后胜负作为在线专家路由。

正向分组即便尚不显著也值得有界验证；显著负向分组尤其应阻止无差别扩量。Qwen 研究不需要额外模型同意，但也不据此宣称适用于所有模型。
