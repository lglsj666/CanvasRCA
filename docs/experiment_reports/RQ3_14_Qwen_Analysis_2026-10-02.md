# RQ3.14：全窗口观测与绑定修复的完整结果分析

日期：2026-10-02（America/Toronto）。实验：`rq314_unified_observed_v1`。本报告为本轮正式结果的详细报告；资格记录、历史输入、回答、分数及失败记录保持原样。单一主 agent 完成离线审计、统计和解释评阅；未调用新模型，也未开展独立盲审。

## 1. 结论先行

**正式队列完整结束，但预选的 WINDOW_VISUAL 不通过采用门槛。** 这次证明了统一 renderer 路径和恢复运行流程可以完成全矩阵，没有证明视觉曲线方案同时提高三个数据集的 MRR、降低成本或提升理由可信度。

- 预选曲线方案 V 相对原始文本 R：AIOPS-2022 配对 MRR **+0.1173**，AIOPS-2025 **−0.0209**，AegisLab **−0.0112**。不能将 AIOPS 合并后的正差异解释为两个 AIOPS 都改善。
- V 没有胜过强文本 T、文字截图 P 或去掉曲线/条形标记的 M。主要比较均未通过注册的 Holm 校正；V−T 的事件组校正 p=**0.052700**，仍未达到 0.05，不能四舍五入判通过。
- **可靠的正向结果来自全窗口摘要文本 T 相对读法规则文本 S**：218 对病例 ΔMRR=**+0.0469**，病例 pH=**0.016502**，事件组 pH=**0.014463**；这是预注册次要比较的结果，不是预选视觉方案成功。T 的三数据集 MRR 为 **0.3014 / 0.3085 / 0.5772**。
- Aegis 的旧 20 例上，视觉损失从 RQ3.13 的 −0.1292 缩小至 −0.0583；新增 80 例的差异为 +0.0006。**部分修复与扩大样本共同造成整体下降看起来变小，不能宣称 Aegis 已修复。**
- V 的每病例配对总 token 成本比 R 高 **15.49% / 18.38% / 15.39%**。通过 1.20 上限不等于降本。解释阅读和定向源核验仍发现单位、实体、时间与因果越界错误，正确的根因排名也可能伴随错误理由。

当前决定：按注册停止条件结束此实现，不采用 V，不自动更换布局或继续消耗剩余调用。保留 T 的次要正结果作为后续方法与基线依据；下一步先解决可核验的解释/绑定机制及视觉必要性问题，再决定是否值得另行注册实验。

## 12. 科学判断、后续优先级与停止边界

### 可以据本轮成立的判断

- unified renderer的现有组件、缺测连线策略和完整事实传输可完成本矩阵；工程有效性和推理有效性是两件事。
- 在已暴露eval上，显式全窗口摘要T比规则文本S有校正后的整体MRR收益，但不是所有数据集都已分别验证显著，也没有独立泛化确认。
- 当前V没有证明超过匹配强文本、截图或markless；多个目标方向为负，且成本更高。停止采用此实现有明确证据，不需要无限追加布局来追逐显著性。
- Aegis失败路径已从泛泛的“视觉不好”收敛到可查的实例：早发资源症状抢占排名、时序/类型/实体绑定错误、没有边被当作健康或独立性证明，以及理由修订未同步输出排名。

### 不能据本轮成立的判断

不能说所有视觉编码都无效；也不能说已经识别了独立的因果机制、获得成本压缩、提高解释可信度、完成独立test或满足RQ3系列性能目标。预定36例解释阅读已完成，但全量、逐轴、代表性grounding率未完成；25条定向审核不能顶替它。

### 建议下一步，先做什么、暂不做什么

1. **收束主线为“保留可诊断事实，约束证据到实体/时间/类型的绑定，验证何时图形有额外价值”。** 将T冻结为重要强文本基线，保留R及历史强基线，不再默认候选参考预测或复杂竞争矩阵有效。
2. 若继续开发，先做离线、可复算的最小机制资格：引用ID是否真属于该实体；时间先后比较是否成立；源单位是否已知；局部延迟和全局duration是否混用；缺边/无日志是否被非法当成排除证据；最终排序是否与理由一致。优先用公开源事实建立规则，不用私有root、fault_type或历史胜负作为输入。规则应拒绝无依据断言，而不是伪造健康证明。
3. 视觉后继只有在明确了**现有控制无法解释的新、可证伪机制**及独立适用性依据后才值得注册。需要与T严格匹配字段和重复次数，保持实体/时间绑定、分开检验真实marks的贡献，并继续沿用统一renderer与跨缺测连接规则。当前“曲线多画一些”或“换布局再试”没有充分依据。
4. 若另行注册一次实质修订，仍应预先选定一个方法，锁定AIOPS/Aegis收益、文本/截图/marks控制、总成本及理由核验要求；不按本轮标签选择数据集专属胜者，不反复调test。若没有新的机制依据，就转入负结果/适用边界整理，而非自动续跑。

以上是基于结果的建议，**本次没有实现新方法或启动任何后续模型实验**。冻结协议要求本轮失败后停止此实现；剩余6调用不自动使用。

### RQ3系列完成了吗

**RQ3.14这次注册矩阵及本报告完成；RQ3总体研究目标尚未完成。** 当前只是220 exposed-eval开发批次，尚未形成满足既定独立部署指标、成本和可信证据链的单一方法；历史test360 MRR≥0.65及两AIOPS各≥0.60目标没有被本轮验证。必要收官需预先冻结方法与强基线、完成匹配预算/机制/鲁棒性及代表性解释审核，且清楚界定泛化证据和数据暴露。新独立确认必须有经审计的独立事件，不能把已暴露eval重新命名成test。测量目标不是保证，也不能靠无限测试调参兑现。

### 单一研究者复审结论

比较和分母保持注册口径；负结果、模型零分、14个未知结果及50次unknown-usage尝试全部保留；没有泄露标签到模型，也没有通过事后最佳arm或重复挑选改变预选方法结论。主要剩余限制为：已暴露数据、部分事件组依赖、样本/故障组小、一个模型/seed、恢复批次差异、表示包不完全隔离视觉变量、少量metric单位与旧排名字符串歧义，以及非盲且定向的解释核验。将这些限制写入结论比扩大性能宣传更符合当前证据。
