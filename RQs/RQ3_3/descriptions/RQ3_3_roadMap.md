# RQ3.3 roadMap

当前完成的是实现准备，不是实验结论。所有执行步骤须在用户另行授权后开始。

1. 核查真实源字段、历史输入和测量定义，冻结分区身份及校准补丁。
2. 运行有界 CPU 回归，人工检查原输入、见证、图像和变换的实际差异。
3. 分别完成逻辑 smoke 与完整输入输出审核；保留未完成的 live 覆盖说明。
4. 先做来源语义校准，再做维度筛查与嵌套预算敏感性比较；联合统计控制不参与部署择优。
5. 锁定方法，在事件组不交叉的开发检查集判断是否值得扩大。阴性结果不换第二名再试。
6. 仅在有进展时开展主比较、视觉/机制实验及锁定回归；用共同背景证据对和绑定控制拆解效用，但不冒称信息量测定。独立事件必须先通过历史暴露审计。
7. 结合排名修复、破坏、信号来源和解释引用，形成 findings。方法不成立则报告并结束该分支，不自动转向训练。

具体数量、阈值、失败处理和入口见 [实验协议](RQ3_3_experiments.md) 与配置，不在本 roadmap 另立参数来源。
