# RQ2.1 qualitative road map

Retire the old study with an explicit account of the input-collapse and bridge
failures. Preserve history rather than replacing inconvenient outcomes.

Establish the bridge before optimizing. Preserve original requests and results,
and use the registered parent projection for the calibrated baseline.

For selection, ask whether an action actually changes the evidence presented.
Natural ties are valid; a renamed implementation with no effective intervention
is not an algorithm comparison. Prefer faithful source adaptation to plausible
but untested replacements.

For silhouette encoding, keep the selected information and card membership
fixed. For composition, also keep the internal encoding fixed. Packing failure
must be separated from renderer bugs and from model-reading failure.

Use the same parent anchors throughout: P0/D0 for silhouette changes and
P0/S0 for composition changes. Do not choose or consume a champion. Preserve
every registered condition, including null results and losses. Use these
contrasts to examine failure mechanisms, not to claim a globally best design.

The authorized baseline-only successor uses static checks and inherited smoke
evidence under the explicit user waiver. During a run, repair demonstrated
implementation failures, not low accuracy. Restart only incompatible unfinished
or affected units. A source/prompt change requiring scientific reinterpretation
must be recorded before any resumed call.

After completion, recommend to RQ3 only actions with traceable changes to
selected facts, visible pixels, model input and downstream outcomes. Null or
mixed results may justify restricting the design space instead of training a
more complicated Composer.
