distributions improve root ranking beyond the same continuous facts in text, and
whether that effect depends on the requested number of ranked candidates.

failed. This is a newly registered development experiment, not a successful

## DD-RQ316-01: Test marginal marks and output capacity without changing evidence

**Date:** 2026-10-03. **Status:** provisional scientific candidate; adopted protocol.

**Context.** The selected RQ3.15 joint method failed adoption. Marginals had the
highest exploratory mean, while AegisLab top-5 coverage fell and lists shortened.
**Decision.** Prospective eight-arm factorial with a same-text markless control;
stop after qualification in this session. Neither fixed-five nor marginal glyphs
are assumed to improve RCA. **Evidence.** RQ3.15 all220 exposed eval: marginal
MRR .4692, pair text .4280 (different available denominators); joint minus marginal
paired MRR -.0134; all primary case/group Holm tests nonsignificant. Full artifacts
and historical review manifest remain linked from the plan and qualification.
**Alternatives rejected.** Promoting the highest mean would be posthoc selection;
rerunning joint layouts would ignore the stopped mechanism; compressed/all-visual
inputs would confound evidence loss; five-rank visual alone would give an unmatched
output intervention; dropping difficult relations would create a new selector.
**Consequences.** Keep same facts, PNGs, roster and scorer; charge contemporaneous
FLEX replications; require four corrected primary contrasts, cross-dataset and
cost/coverage guards. Failure ends this candidate, with no automatic layout loop.
