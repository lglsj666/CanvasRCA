## DD-RQ45-2: Source ownership, not string deduplication

Samples and all statistics in the two pair tables are one dependency closure. Different pair relations remain different original records for source-geometric sampling (`request_pair:PAIRxx`); reference/current and parent/child support of that record share the source group. Equal entity IDs or numerical readings never merge unrelated observations. All original occurrence IDs survive in audit.

Graph edge records transfer together, including repeated occurrences, typed roles and genuine supporting-span counts. The `propagation_service` onset/severity/rank fields are telemetry observations, not derivatives of topology simply because they occur in a G section; they remain in the original residual text. Shared graph endpoint labels and marginal parent/child identity labels are necessary joins. No relationship is inferred from equality of IDs or proximity.

No-pair fallback is H_TOPOLOGY for both pair-bearing hybrid conditions; no error/capacity fallback. Untransferred records retain original order and number spellings. Fully transferred graph containers are removed; a mixed table preserves its columns and remaining rows using the registered lexical serializer. No packed-string re-encoding of residual records.

## DD-RQ45-3: Native complete marginal component

Old `trace_joint.marginals` lacks exact per-request correspondence and all population statistics. The new opt-in `trace_joint.complete_marginals` exposes exact labels beside real paired glyphs, binary joint-count cells, quantile glyphs and conditional annotations. Existing registry entries/components are preserved. Exact values hidden only in metadata do not qualify.

## DD-RQ45-4: Bounded execution, not implicit authorization

1700 attempts total: formal 1560 (1320 main, 180 QA, 60 independent repeats), smoke 18/600 seconds, infrastructure retry reserve 122. Static, CPU, smoke and formal are separate states. Only static is authorized for this implementation. GPU activation needs complete source-matched CPU and explicit separate authorization; formal also needs passed smoke. No quota resets or model correctness retries.

Protocol defines the four-event-group Holm comparisons and historical cost/performance targets. The third primary contrast changes both selection/count and does not isolate the algorithm. Static checks do not establish cost decline, actual glyph legibility or a ranking improvement.
