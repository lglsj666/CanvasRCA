# RQ3.19 functions

- main.py: compatible unified PNG preparation, canonical transaction and
  scorer integration, interleaved core queue, owned serving and safe resume.
- utils.py: immutable configuration/roster, public QA eligibility and hash
  selection, source closure, runtime projection and bounded artifact writers.
- exps.py: pure lossless compaction, visible fact transfer, same-fact readouts,
  six typed QA questions, separate request templates and deterministic scoring.
- gates.py: static/history checks, frozen source and authorization credentials,
  runtime/smoke qualification and separate QA/RCA statistical families.
- tests.py: independent source/QA and roundtrip checks, all-case actual
  processor budgets, actual unified DOM/PNG binding, offline lifecycle and gallery.

Five functional modules, <=7,500 lines. No alternate renderer or private-label
dependency in the public compiler. Historical implementations are frozen
imports, not modified source. Runtime activation requires measured passes.
