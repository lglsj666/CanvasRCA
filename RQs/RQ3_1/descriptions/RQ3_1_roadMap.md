# RQ3.1 roadmap

First establish a reproducible data boundary, preserving historical records and
distinguishing current roles from past exposure. If event isolation or exact
assignment cannot be verified, resolve that evidence before model execution.

Then integrate the audited public-evidence, representation and evaluation
interfaces. Advance only after source semantics, visible information, recovery
and bounded qualification are checked. A partition manifest alone does not
qualify the diagnostic pipeline.

Establish a direct textual comparison with locally available values before
attributing gains to vision. Preserve the existing reference/catalogue baseline
and distinguish statically implemented table/screenshot additions from qualified conditions.
Qualification and versioned registration precede new calls; a plan change does
not modify an active run or invalidate compatible results.

Develop and select methods using the registered eval pool, preserve versions,
then lock the method before the final test. Explain results using same-content
controls and source-grounded evidence, reporting legacy exposure and failures.
Composer learning remains conditional future work, not an automatic next step.

Complete the machine-diagnosis evidence chain without participant recruitment
or mandatory independent annotation. Use explicit-assertion checks within their
measured scope and input interventions for behavioral evidence. If visual gains
survive strong text controls, explain where; if they do not, retain the selection
findings and narrow the visual story. Human productivity remains future work.
