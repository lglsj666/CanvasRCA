# RQ3.8 qualitative roadmap

Use the accepted operational dashboard to separate useful graphical support
from extra visual competition, with an intact text safety net. First demonstrate
faithful projection and fixed-slot interventions; qualify the new deployment;
then run the registered comparisons without adapting to partial accuracy.
Interpret repairs and harms by observable patterns as well as root granularity.
Preserve negative results and distinguish source coverage, readable rendering,
actual model use and correct diagnosis. Further method development depends on
those results rather than an assumed visual winner.
