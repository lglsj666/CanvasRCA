# RQ3.12 road map

v1失败保留。用户恢复v2资格检查后，完整CPU功能/图像/容量/输入成本通过，但两个AIOPS没有可比较的竞争预测，方法readiness失败。当前停在GPU前，未调用模型；下一步须版本化修订参考响应或数据支撑，再重新资格，不能降低门槛或继续清理布局来代替方法适用性。

先确认参考期数据能否支撑竞争候选之间可靠、不同的预测，并确认实际 tokenizer 成本与完整上下文容量。模型不适用时保留未知；不得用减少案例、降低资格门槛或参考期外拟合来制造适用性。

若公开 CPU 可行性成立，再审核真实图像、数值与实体绑定、完整模型配方和累计预算，冻结源代码。运行有界 smoke，审阅真实输入输出及持久化后，才可进入整批已注册 eval。

整批结束后，先确认完整性、原评分与统计，再分别解释文本中的诊断计算效应、等信息的视觉效应、数值求解器对照和实际成本。解释审核与准确率相互独立。任何未通过的维度都保留为失败证据，不更换预选方法。

参考预测缺乏适用性意味着应重新审视响应定义或数据支撑；文本与视觉都有效而差异不成立意味着只得到 RCA 前端计算价值；只有在视觉增量与受控成本也成立时，才值得继续压缩共同响应、扩大独立评估或另立训练实验。本轮没有授权这些后续操作。
