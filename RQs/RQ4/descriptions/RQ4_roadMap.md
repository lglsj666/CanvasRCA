# RQ4 路线与停止边界

用户随后授权的小例子接口验证已完成：真实 Qwen 权重、三个旧 eval dashboard，12 次调用；
裁剪视觉 token 后可以生成，identity 与原生等价。[报告](../../RQ4_1/findings/exp_token_interface_probe_findings.md)。
没有从被删除的 RQ3.22 继承执行权限、资格、额度余额、方法代码或实验队列；此前已消耗调用不会因换编号消失。

1. 首先核对统一 renderer 的证据/区域映射与真实视觉 token 几何，以及现有模型是否可接入受约束视觉压缩。冻结证据选择，防止同时改变内容和表示。
2. 模型级接口已成立，vLLM 生产接入仍待验证。按用户最新要求设计更广的首轮实验，总上限 10,000 次（已用 12）；覆盖强文本基线、常规纯视觉、同预算通用视觉压缩与结构约束视觉压缩，并明确各比较回答的问题。基线不是视觉方法内部的文本旁路。
3. 经授权后实现、静态及 CPU 检查、图像审查、GPU 资格，再运行登记批次。当前没有授权跳过新方法所需的资格，也不自动继承旧 CPU 豁免。
4. 以实际 MRR、AC@5、全分母、总输入输出成本和运行开销决定继续或停止；小比例机制工作检验绑定和局部细节，QA 不给 RCA 传答案。
5. 冻结合格方法后，完成曝光审核允许的验证与论文证据链。失败时停止该候选并记录原因，不自动恢复混合输入或继续枚举布局。

近期下一步是把实际接口可行性转化为有界、可资格验证的研究计划；完整实验仍未启动。
