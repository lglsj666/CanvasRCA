# RQ4.1 CPU admission: source semantics and independent audit

This version implements the registered full-roster CPU gate after the small
three-case evidence-budget investigation. No RCA requests, GPU smoke or formal
launch are enabled by this work. Old PNGs, supports, masks and failures remain
under their original version directories. New artifacts use `cpu_admission_v4`.

The source audit found that nested pair statistics were displayed with numeric
array paths rather than decoded column meanings. The compiler now labels
parent/child, reference/current, binary-group conditions, conditional child
quantiles and native units explicitly. Values and source occurrences are not
changed. Captions containing identity, descriptive strings, rank or anomaly
metadata are not numerical allocation operands. Numerical operands have their
actual quantity/unit/phase; legitimate paired captions contribute the already
registered self-change relation. This is a correction to the existing typed
source contract, not an outcome-tuned edge selector.

`CanonicalForegroundV2` is an additive audit variant of the existing unified
renderer foreground operation. Caption values not designated canonical
numerical operands remain mandatory context, alongside identities and reading
labels. V1 behavior and the ordinary diagnostic renderer remain unchanged. V2
does not add a new dashboard drawing component. Numerical/metadata boundaries
and complete source binding are checked before extracting support or features.
The corrected source labels change the current PNG; old encoder features and
selected masks therefore cannot certify this version.

The independent audit decodes original sequences separately, verifies values,
positions, missingness, units, request samples, candidates, relation sets and
directions, and reconciles each original scalar occurrence with its rendered
binding. Mutation tests must reject incorrect samples, units, graph direction
and candidates. Source binding alone does not establish readable pixels.

T_FULL and T_NATIVE retain the complete frozen RQ3.21 RAW_TEXT request content.
T_LEDGER serializes all source-ledger records with an explicit codec and pair
column legend. T_DEP stores each record once, grouped by connected components
of the same public comparison dependencies; records without a multi-role link
remain in the global area. Shared task wording is representation-neutral. The
new compilers do not import historical answers or private labels. All input
lengths must pass the unchanged actual-processor/context gate.

All thresholds, evidence-budget ratios, rewiring rules, public seeds, input
facts and call budgets remain unchanged. CPU failure cannot be repaired by
dropping cases or changing the preselected ratio. Source/renderer/processor
checks are staged before feature extraction and final mask qualification.
No source-only or small-scope result is labeled full CPU admission.

The clock audit additionally fixes metric-phase attribution to the inherited
equal-width bin center `(i+0.5)/n`, as computed in the frozen metric projection,
rather than the endpoint interpolation `i/(n-1)`. Eighteen cases have a different
boundary-bin classification; one has no observed sample at that boundary, so
seventeen provenance maps change. Only the affected audit rasters are regenerated.
The full diagnostic PNGs and source values remain byte-identical. This correction
does not turn a bin aggregate into an exact within-bin event timestamp.

The outcome-free statistical stress audit uses the inherited 193 development
event groups. It has 54 registered stress cells, 2,000 replicates and 4,999 sign
flips per replicate, with zero shift and shifts 0.02/0.03/0.05. Its maximum null
rejection rate is 0.0935; five cells exceed the registered 0.07 alarm. Inference
is therefore **uncalibrated** under the registered policy. P-values from this
family cannot support established superiority or independent confirmation.
Engineering development remains descriptive; no replacement test is selected.
A no-confirmation declaration freezes the 2,400 reserved calls as unused. This
does not claim that independent cases do not exist: stock enumeration is not
performed after the preceding confirmation prerequisite fails.

Inherited group namespace hashes differ from the original data split; the
actual case membership sets are identical. Group verification compares those
sets, not namespace strings. No registered groups share an event alias or
overlapping window in the same source. There are 1,977 pairs in distinct groups
sharing a source, so independence across disjoint events remains an assumption.

The final typed-field inspection also found a LOG-R `score` operand left in the
generic caption path, and count units incorrectly inherited by error/log rates.
The original RQ2.1 implementation computes these rates as counts divided by
recorded minutes. Rates now have explicit events/min labels, correct phase and
same-quantity self-change pairs. All anomaly scores and availability metadata
remain visible source context but are excluded from allocation-role weights;
their numerical magnitude never determines an allocation priority. Template
number units remain unverified `source_unit`, not an invented count or duration.
The old source/surface reports are preserved in `before_log_semantics_fix`;
the current source index is `current_render_report.json`. An empty dictionary
in `numeric_preview` exposed an index-access bug in the label formatter: its
78 failed renders are preserved, and only those failed cases were rerun after
the fix. This is not case filtering.

The diversity control initially exceeded the 30-second per-selector limit on
an existing real feature fixture (33.03 seconds before timeout). Its exact
cosine-distance updates now evaluate only eligible candidate rows. The dense
reference implementation remains available for qualification. On that same
fixture the optimized path took 2.89 seconds versus 34.14 seconds for the dense
reference; final masks and role qualities were identical. This is a local
implementation optimization, not full-roster runtime qualification.
