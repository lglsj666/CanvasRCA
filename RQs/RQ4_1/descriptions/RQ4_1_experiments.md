## 核心创新与研究主线

**利用绘图时可核验的公共来源关系，把一次比较需要的多个操作数共同纳入视觉 token 的预算分配；检验这种正确依赖是否在同样元数据和预算下，比独立区域保留更有诊断价值。** 方法暂称 CVC（comparison-preserving visual coding）。

例如，同一服务的 reference/current 耗时及其实体、单位、阶段需要共同可用，才能支持一次合法比较。数据进入统一 renderer 时已经具备这些来源关系；本轮尝试将它们编译为预算分配约束。这里保留的是可用于比较的图元覆盖代理，不保证 VLM 一定读懂，也不把 token 几何位置等同于全部信息内容。

流程是：完整的冻结公共证据 → unified renderer 图像及审计映射 → 原 Qwen 图像编码 → 确定性预算分配 → 一次根因诊断。模型收到的病例事实和候选 ID 全部在图像中；文本只说明任务、读图方式和输出格式。无训练，无模型驱动的前置取证，无文本诊断信息兜底。

这利用了图形可定位的图元、共享坐标与模型的视觉特征空间。遥测本身仍可用文本表达，因此不宣称视觉拥有文本在信息论上不能表达的事实。潜在优势是表示与计算效率，必须由实际排名和完整成本验证。

## 为什么有可检验的新意

图、token 剪枝、覆盖、保护互补证据都已有前例。本轮的具体差别是将**真实绘图来源中的类型化比较依赖**编译到压缩接口，并设置足以推翻这一解释的对照：相同图像、相同 token 数、相同来源与单体权重，分别独立分配、按正确依赖分配、按保持度数的错误依赖分配。收益若只来自普通覆盖，就不能保留依赖机制的结论。

核心机制对照是 CVC50、UNARY50、REWIRED50、QUOTA50。完整精确文本 T_FULL、获得相同比较组织的 T_DEP、生产后端 T_NATIVE 保护强基线。像素的有限精度与原文不同，整个视觉/文本比较是系统比较，不冒充完全同输入的纯模态因果实验。

预选方法固定 CVC50。25%/75%只是成本—效果曲线；最高分臂不能事后取代它。主矩阵共有22条件，包括四种原论文剪枝方法的合格适配，以及一个独立探索臂。若原方法不兼容则 not-run，不把它记作零分，不重新分配其预算。

## 一个独立探索臂

**CONTRAST_ATLAS（变化对照图谱）**押注另一个直觉：把实体的自身变化与相对已观测同组实体的差异并排展示，可能让模型更容易区分共同变化与局部特殊表现。它保留原始证据和共同变化，不把最异常者直接判为根因；使用全部视觉 token，不继承 CVC 的剪枝算法。只运行一个固定方案、220例，不搜索多个参数，不自动占用核心方法的独立确认预算。

该臂新增公开可复算的统计和表示，因此结果只能支持整套探索方法的效果，不能用于证明 CVC 的机制。所有图像仍须经过统一 renderer，必要的新组件只做有类型定义的增量注册。

# Final protocol — renderer-assisted comparison-preserving visual coding

Date: 2026-10-06. Research design, not implemented or qualified. No positive RCA result claimed.

## 1. One contribution and its falsification

**Proposed contribution: use a renderer's public provenance to preserve the joint support for legitimate comparisons while compressing visual tokens, and establish whether correct dependency structure matters beyond equally informed regional preservation.** The target system diagnoses an incident in one frozen-model call from a dashboard, with no incident facts in the surrounding text. Static reading/task/output instructions are permitted. Strong text RCA systems remain direct competitors.

This is deliberately a narrower contribution than a general new token-pruning theory. The new candidate is a provenance-assisted compiler for instrumented graphics, not an arbitrary-image pruner. Its potential advantage is complementary evidence allocation: a reference value, current value and their ownership/units must remain jointly usable. Preserving salient individual objects or many readable values need not preserve that comparison. No claim says this phenomenon or protecting context was previously unknown.

The claim fails if correct dependencies offer no advantage over the same metadata with additive independent-region allocation or degree-matched incorrect dependencies. It also fails as a deployable pure-visual RCA proposal if it cannot improve ranking relative to complete strong text at comparable actual cost. A useful generic coverage result would be reported under that narrower description, not renamed as proof of the proposed dependency mechanism.

All telemetry can be serialized as text. The proposed advantage is computational/representational, using the frozen visual encoder and spatial features with direct token-budget control, not information that text is mathematically unable to express. Source completeness is not exact numerical reversibility of pixels.

## 2. Prior work boundary and present evidence

The closest known work includes G-Prune (semantic-similarity graph), SCOPE (saliency plus token-set coverage), DART (duplication/diversity selection), S²Prune (regional coverage and detail allocation), Focus-then-Context (subject/context preservation), DeFT/When Text Matters (support/value failures and deferred selection), CoVeR (geometry-derived exact-budget coverage), and SemVID (connected evidence with complementary roles). None of these broad ideas is claimed as ours. The specific candidate distinction is **renderer-derived, typed operand dependencies plus controlled true-versus-rewired dependence**, beyond metadata-matched unary coverage. A literature comparison matrix and implementation comparison are required before claiming a new algorithm.

Primary sources: https://ojs.aaai.org/index.php/AAAI/article/view/32427 ; https://proceedings.neurips.cc/paper_files/paper/2025/hash/ec6b4456c2bdfd04002d7984043c4936-Abstract-Conference.html ; https://aclanthology.org/2025.emnlp-main.505/ ; https://arxiv.org/html/2609.01224v1 ; https://arxiv.org/html/2605.20950 ; https://arxiv.org/html/2609.34861v1 ; https://arxiv.org/abs/2609.08345 ; https://arxiv.org/abs/2603.05663 . Recent arXiv items are not assumed accepted unless separately verified.

A prior technical probe used 12 short local frozen-BF16 calls on three actual dashboards. Identity embedding injection matched a manual native-image path's first logits and generated tokens; halving 875 visual tokens retained those three short responses. Quarter retention damaged one entity reading; native itself misread phases. This establishes only limited model-interface feasibility. It does not establish standard `generate`/vLLM parity, ranking utility, accuracy, or end-to-end savings. The installed production server lacks native pruning for the hybrid recurrent/full-attention architecture. An audited adapter is a prerequisite, not an already available feature.

## 3. Fixed evidence and pure-visual compiler

Development uses 220 already exposed cases: three datasets with 60/60/100 cases and approximately 193 event groups. The original source roster, candidates, full public M/R/L/G records, samples and summaries are frozen from an existing complete strong input. No new label-based selector, abnormality ranking, training, model-driven acquisition, or extra diagnostic call.

One fixed dashboard compiler is used for ALL controlled pruning conditions. The separately declared CONTRAST_ATLAS wildcard (§17) has its own fixed representation and derived public summaries; it is excluded from same-image/metadata causal claims. It reuses the existing unified renderer's registered metric, trace, log and relation components, with candidate IDs and reading keys inside the image. Legitimate before/current comparisons use shared axes and explicit ownership labels. Calls and deployment remain observed relations, not causal claims. Full log/template strings and node/resource evidence remain; the old whole text prompt is not rasterized as a screenshot. Every source fact has a visible owner and audit binding. A curve encodes its original samples at original coordinates; drawing across unobserved positions neither creates values nor adds missing-data warnings. Fonts, processor limits and canvas policy are frozen before outcomes. No new layout search, merged-latent method or header-sink method is in this study.

Three text baselines: **T_FULL**, the exact complete strong prompt/evidence with an audited representation-neutral task wrapper and the existing fixed-five ranking schema; **T_LEDGER**, complete readable serialization of the visual compiler's source ledger with displayed precision and explicit incidence/units; **T_DEP**, complete precise text organized using the SAME comparison dependencies as the method, keeping an independent global region for unowned facts. It does not receive root hints. T_FULL retains exact observations and cannot be truncated/weakened to manufacture a win. T_LEDGER is an auxiliary representation audit, not a replacement for T_FULL. Any comparison still involving unequal pixel precision is described as a system-level comparison, not a pure modality causal effect. These are strong local compiler baselines, not a claim to reproduce all RCA SOTA systems.

Full text and full visual must fit unchanged context limits. If rendering all fixed evidence with legible registered fonts and correct processor geometry is infeasible, the source representation is not qualified. The method does not secretly drop facts, increase pixel caps, or fall back to text. Pre-model structural infeasibility is retained and reported separately from model errors.

## 4. Public dependency representation

The renderer emits an audit-only map to actual post-processor/post-merger token positions. Tokens are not forwarded as case-specific text. The map uses source public IDs and an explicit whitelist; labels, historical answers and anomaly scores are unavailable.

A semantic role key is `(source occurrence, entity, signal/operation, recorded quantity kind, original unit, public phase/window)`. Repeated renderings of one source occurrence map to one role; distinct source occurrences are retained even if IDs or values repeat. Reference/current operands must have the same measured quantity and unit; their own recorded durations are compared without cross-host elapsed-time subtraction. The fixed public bundles are:

- matched reference/current of one recorded entity/signal/operation (two roles);
- parent and directly observed child, each with reference/current recorded duration (four roles), only if the original public evidence supplies all four;
- same-signal same-unit observed peer instances connected through an already-public service/node membership (pairwise, no asserted healthy reference);
- every unpaired role, including node/resource/log evidence, receives a singleton edge.

No new bundle is inferred from temporal proximity or label-known fault relevance. Deduplicate edges by sorted role identities plus type/direction; duplicates are not additional evidence. Use constant edge weight within each type: if B nonempty types are present and type t has m_t unique edges, every such edge has w_e=1/(B*m_t). Every type has a fixed arity (self-change2, observed-parent/child4, peer2, singleton1). This caps each type's total mass, but DOES NOT guarantee equal importance for high- and low-degree roles within a type. That public-structure weighting is disclosed and shared by all controls. Deduplication removes repeated annotation of the same edge; genuinely different source occurrences remain. No claim of arbitrary duplication invariance is made.

For every role u and type t the additive coefficient is a_(u,t)=d_(u,t)/(B*m_t*arity_t). Rewiring preserves the degree for EACH role and type, edge count and arity; therefore every a_(u,t) is exactly unchanged. The CPU audit independently computes these coefficients before and after rewiring, and rejects any discrepancy. The UNARY objective is identical under the original and rewired graph: only the higher-order min coupling changes algebraically. The implemented heuristic also proposes bundle-dependent joint actions, so rewiring can change its search path. The causal contrast is the registered dependency-aware compiler PLUS solver, not a pure objective intervention at equal optimality. Singleton edges are never rewired.

Candidate, identity, unit, phase, axis, direction and necessary log glyph tokens form anchors A. Each source occurrence has one canonical plotted occurrence chosen by component priority in the frozen renderer schema, then stable component ID. q uses only that canonical plotted support; other visible occurrences are listed but are not extra roles or extra weight. Original distinct source occurrences are not deduplicated by value. Under the user-authorized shared-support revision2, every role receives all non-anchor positions intersecting its canonical foreground; R_u sets may overlap. Selecting one index updates every supported role but charges and forwards the original token only once. This supersedes the archived exclusive largest-area ownership rule; duplicate presentations remain audit-only and do not add semantic weight. A is excluded from every optional R_u. If a role's entire canonical foreground is in A, that role has q=1; a role with empty optional support whose foreground was not fully anchored is a mapping failure. Adding duplicate annotation entries at fixed PNG, features, geometry and K must leave the graph/objective/mask unchanged. Repainting a second glyph elsewhere is NOT claimed to preserve embeddings, support geometry, masks or q. The same maps and A are used by all controlled pruners. Tokens containing inseparable multiple-role foreground are counted as ambiguous, not proof that both operands survived. Empty role support or excessive anchor demand is a declared qualification issue; no hidden text bypass.

The image encoder globally mixes information. Geometry here indexes **where an embedding came from**, not all information encoded inside it. Neither deletion nor retention of a token position is called deletion/preservation of the corresponding fact.

## 5. The candidate algorithm and matched controls

Let N be original visual-token count, K=ceil(rN), and start S=A. If |A|>K, that ratio is infeasible. CVC and its matched pre-decoder controls use exactly K original embeddings from decoder layer1 onward, original MRoPE coordinates and a fresh per-request cache. This invariant does NOT apply to prior algorithms that prune updated states inside the decoder; their explicit layerwise contracts below take precedence. No masked full-length sequence is billed as K-token inference.

For role u, token support R_u, normalized projected features z, and actual 2D positions p, define

`d_u(i,j) = 0.5*(1-cos(z_i,z_j))/2 + 0.5*min(1, ||p_i-p_j||² / max(role_bbox_diagonal², one_patch_diagonal²))`.

`q_u(S) = mean_{i in R_u} max_{j in S intersect R_u}(1-d_u(i,j))`, with max over empty set zero.

Feature zero norms use cosine zero except identity itself, which has similarity one. Accumulation FP32, values clamped for numerical error. This is a geometric/feature coverage proxy, NOT a comprehension guarantee. Unlike a small token-count quota it has no artificial square-root saturation: unrepresented distinct spatial positions retain residual distortion. Foreground mapping and fixed semantic roles avoid redefining the objective merely by splitting a rectangle.

The proposed objective is `J(S)=sum_e w_e min_{u in e} q_u(S)`. The metadata-matched **UNARY** replaces min with arithmetic mean, keeping incidence-derived role weights, features, A, compute accounting and the same solver. **QUOTA** allocates K−|A| residual slots proportionally to |R_u| by largest-remainder rounding (stable role-ID ties), caps each allocation at |R_u| and repeatedly redistributes excess to unsaturated roles. Within each role it greedily maximizes the same q_u, stable token-index ties. If all role supports are exhausted, fill remaining slots from non-role tokens by spatial farthest-point selection. **A_UNIFORM** selects all residual slots by spatial farthest-point distance from the current S over the original normalized 2D grid, ties by original index. Its name denotes uniform spatial coverage, not random sampling. If A is empty, start at the grid-center-nearest token, stable-index tie. This same deterministic rule fills non-role slots in other methods.

The fixed heuristic enumerates all single-token additions and, for each bundle, a joint action containing the best-q-improving next token for every currently minimum-quality role (ties within 1e-12). Evaluate each action's ACTUAL full-objective gain per new token; exclude actions exceeding remaining budget. Tie order: primary gain per token, absolute primary gain, weighted unary gain, lexicographic sorted token indices. Single additions remain available through the final slot. Only when every feasible action has zero primary and zero weighted-unary gain (absolute tolerance1e-12), take ONE residual token using the A_UNIFORM spatial farthest-point rule and continue; otherwise use the preceding gain tie order. This identical terminal rule applies to CVC, UNARY and REWIRED. There is no positive-gain fill step that ignores the objective. It is a deterministic heuristic, not a claimed global optimum or submodular approximation. Incremental cached distances and sparse role updates are mandatory; actual selector runtime counts toward cost. Tiny exhaustive instances report achieved objective and optimum gap, including unequal role sizes, overlap, budget remainders, singleton observations and zero-gain plateaus. For paired true/rewired toy graphs report each own exhaustive optimum, heuristic gap, cross-evaluated objectives and selected-mask difference. This separates solver artifacts descriptively; it does not turn the model comparison into an objective-only causal proof. Include partial-anchor and fully-anchored toy roles: q evaluates residual support and jumps to the stipulated1 when all foreground is anchored, so it is not a calibrated common-scale readability measure.

**REWIRED** runs exactly the same algorithm with typed degree-preserving double-edge swaps. For a two-role edge, swap endpoints between two edges; for a four-role edge swap one same-role-type incidence between two bundles. Reject original edges, self/duplicate edges and incompatible unit/phase/arity. Match operand area and feature-dispersion bins and geometric-distance bin under the precise contract in §15. Seed and edge order come from a fixed registration hash. Exactly100*m_t proposals per rewritable type, stopping early only if fewer than two eligible edges exist; report proposals, accepted swaps, final changed-graph status and final changed-mask status separately; cases with no legal swaps remain identical and in the denominator, with a separate prequalified diagnostic stratum. The PNG, role sets, labels, A, individual feature vectors and K do not change; only the allocation dependency graph does. Misleading edges are never drawn or given to the model as facts.

Before calls, report selection Jaccard, token allocation by role, correct-bundle proxy values and accepted-swap fraction, final graph-change fraction and final token-mask-change fraction. If rewiring never changes allocation, the method has no executable dependence mechanism at that ratio: do not spend its RCA budget or claim the mechanism. No tuning against RCA answers is allowed to force the masks apart.

## 7. Mechanisms integrated with the main comparison

Before new responses, select90 cases (30/dataset), using event-group rotation then hash; never select on rankings or QA. At most14 extra calls per case:

- Four independent repeats: one additional complete single-call diagnosis for T_FULL, V_FULL, UNARY50 and CVC50 (360 calls). Same prompts/images/recipe, separately generated registered seeds; repetition is not another stage of diagnosis.
- Four independent QA calls, same six factual questions under those four conditions (360). Two paired-value readout questions, two paired ownership/unit/phase binding questions, and two comparisons: the six questions form TWO linked three-question blocks on two fixed reference/current operand pairs, as defined in §16. Report joint correctness and binding/comparison conditional on both operand readouts, with denominator and selection caveat; these conditional descriptive results are not randomized causal mediation. Question inability stays not-applicable, not replacement. QA outputs never enter RCA.
- Six diagnostic interventions (540): panel-position permutation for UNARY/CVC (two calls); true/false binding swap before encoding for UNARY/CVC (two calls); change-one-operand and same-area irrelevant-glyph perturbation for CVC (two calls). Interventions are separate corrupted-input tests, not proposed deployment methods. Pixel-level edits use the unified renderer and recompute embeddings; token-position and pixel-fact interventions are distinguished. Synthetic mutations do not carry an unchanged real-world root-cause score as ground truth. For factual changes report ranking-set overlap, top-1 changes and public-evidence grounding in the existing output explanation, not an asserted MRR improvement or modified-image QA accuracy. No unbudgeted QA call or separate QA-consistency endpoint is claimed. Position-only permutations preserve facts, candidate order and labels and may be scored with original labels. Exact intervention selection must be frozen using public geometry, and absent matches are not applicable without post-hoc substitutes.

Core mechanistic evidence is CVC versus UNARY and REWIRED on unchanged inputs. Pixel interventions are supporting sensitivity evidence, not a substitute. Attention collection is deferred from this experiment: no extra heatmap-driven replay, memory work or inference dependency is needed for the claim. Future compact instrumentation remains allowed.

## 8. Statistics, performance claims and confirmation

Primary estimand is full-denominator case-weighted mean RR difference (220 cases); report dataset means and equal-dataset macro means separately. An event group's difference is its mean within-group paired RR; no fake independent observations from the questions or repeats. The primary inferential unit is the event group; case-level tests are a labeled sensitivity analysis. All conclusions are limited to this frozen Qwen architecture and instrumented compiler; the three datasets do not establish cross-model generality. Freeze dataset-specific strata for anchor fraction, role-area imbalance and dependency density by public-roster tertiles before answers, and report heterogeneity descriptively without selecting methods by strata.

Six registered main contrasts: CVC50−T_FULL, −T_NATIVE, −T_DEP, −UNARY50, −REWIRED50, and −QUOTA50. The decisive inferential test is a group sign-flip randomization of the original group-size-weighted mean RR difference,100,000 fixed-seed flips with the plus-one Monte Carlo correction, two-sided, one six-comparison Holm family, alpha0.05. The independent-group symmetric-null assumption is explicit; this is not an exact random-treatment experiment. Differences are rounded to12 decimals. Registered two-sided Pratt-zero Wilcoxon and paired dz at group and case level are sensitivity analyses with separately reported six-test Holm adjustments; significant sensitivity results cannot rescue a failed primary test. Neither signed-rank nor mean-against-zero significance proves mean gain at least0.03. No superiority decision is made by picking whichever statistical test is significant. Registered fixed budget/algorithm comparisons are secondary, with their own complete multiplicity family; no per-dataset significance claim from isolated p-values. Invalid model outputs are zero; infrastructure unknowns retain tight original-denominator bounds and paired known-case estimates. Project constraints forbid confidence intervals; point-estimate no-decline screens are therefore explicitly not statistical noninferiority claims.

Before calls perform the outcome-free calibration and power audit in §15 using the actual event-group sizes. It includes zero-mean skew, zero inflation and group-size-related variance.
