# RQ1.1 qualitative road map

1. Preserve the latest RQ1 audit results and prove the initial RQ1→RQ1.1 copy
   was byte-identical.
2. Remove preparation ambiguity and active Qwen3.6 paths while preserving the
   approved Qwen3.8/Gemma inference recipe; collect image and text attention in
   the original prefill as a non-causal diagnostic.
3. Qualify Denum semantic round-trip, renderer inheritance, the 16-cell
   M/R/L/G factorial plus C/S/H controls, the 64-question registry, persistence,
   scoring, exact processor geometry, and area-corrected attention with
   static/CPU checks.
4. Run exactly one bounded two-model smoke for each active experiment. Qwen3.8 and Gemma
   execute sequentially and share 18 calls and 600 seconds. Fix a tractable
   hidden issue and repeat only the affected experiment smoke; stop on an
   unresolved material issue.
5. Freeze a versioned protocol only after both currently active experiment
   smokes pass, their
   raw conversations have been inspected, and every model-visible/tool-returned
   entity is a member of the label-blind exhaustive candidate universe.
6. Run `direct_rca`, then `direct_qa`; within each,
   complete Qwen3.8 before Gemma. Do not choose whether to run a model or arm
   from an earlier result.
7. Join QA and RCA by case, model, and representation. Distinguish perception
   repair/break, diagnostic-evidence repair/break, token compression, region
   effects, interactions, and attention-density changes. A rank change without
   MRR gain is visual influence, not improvement.
8. Keep the abandoned multi-stage implementation as future-work provenance,
   but never include it in active queues, smoke, claims, or result summaries.
9. After RQ2 finishes, qualify and then run the separately versioned one-stage
   counterfactual RCA experiment. Keep its renderer, prompt, preparation,
   roster, model recipes and scorer entirely RQ1.1-owned. Use targeted,
   placebo and neutral visual controls to distinguish directed image-semantic
   influence from generic rank instability; do not treat sensitivity alone as
   proof of accurate or faithful causal reasoning.
10. Use C−T to measure nonvisual structure/compression and V−C to isolate
    spatial visualization beyond that compression. Treat client/GPU/render
    timing as machine-specific operations data; use tokens for portable cost
    comparisons.
11. Regenerate V3 first, then reuse all 480 frozen incident identities. Keep
    all active RQ1.1 calls within one aggregate 40,000-call budget; current
    registration totals 39,360.

Negative, null, or mixed outcomes remain valid; RQ1.1 is not designed to prove
that images help. A redesign is justified by a concrete
failure mode—fact inequality, perception failure, tool misuse, or unstable
scoring—not by the desire for a positive visual result.
