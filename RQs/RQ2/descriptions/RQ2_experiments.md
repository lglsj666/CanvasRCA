# RQ2 Experiments

The initial experiment is a complete two-level, four-factor design over metric
encoding (M), graph encoding (G), cross-source arrangement (A), and entity
ordering (O). Sixteen cells provide eight matched anchors for every main
effect. Interaction analyses use the same anchor states.

All cells use the three global contracts in `configs/`. Label-blind salience
may use robust anomaly magnitude, persistence, source presence, and topology
degree; it may not use root labels, fault type, injection time, case identity,
dataset, model output, or paths.

The Nibi refactor prepares the static design only. Model execution remains
disabled until a future registered run freezes render implementations and
rosters.
