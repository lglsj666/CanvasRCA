# RQ2 Road Map

Start from a complete equal-fact factorial design. Inspect main effects before
interactions, retain exact lookup as a negative control, and use matched anchor
states to avoid attributing a layout-context change to one action. If a design
action helps only one model or dataset, carry it forward as a conditional
choice. If no stable action improves RCA, use the failure analysis to reduce or
redefine the design language before moving to contribution modelling.
