1. 将反复出现的嵌套字段名展开成明确列名；同一组记录共享常量字段，保留每一行。
2. 对实体、fact ID等已经逐项核实相等的字段使用显式引用，保留原字段含义。
3. 解析原来包裹在文字中的公共JSON记录，统一使用命名列；保留记录出现次数、顺序和全部附加说明。

6. 取证目录只列出概览尚未展开的序列、AUX、配对样本和组件序列。已经完整出现在概览里的短Trace/日志摘要仍保存在概览和原账本，但不再用它们冒充新增明细。资格检查至少要容纳一个**含新增观测的完整包**。
7. 实现按优先级、按实际完整请求token整包放入的函数。超预算包跳过，后续较小包仍可加入；不截断数组。无效选择返回无新增明细的概览，概览自身超限则报告需要共同回退。

全部220例 v2 canonical public packet 与 v1 **逐包完全一致**；压缩发生在发给模型的文本表达层。完整F、候选、原文账本、可取回原始包和拓扑源均未修改。两种取证表示共享同一压缩后的非图形事实和预算算法。

## v2 为什么视觉侧还没通过

文字关系清单已经压缩，而完整节点箭头图仍按现有布局绘制。真实视觉选择输入平均为9,881.7、8,809.5、10,955.9 token；相对同病例紧凑文本请求，分别多约1,834、1,988、2,997 token。这是**图像替换关系文字后的净输入差**，不是图像token本身。

216张关系PNG全部通过统一renderer生成；画布宽1440、字体18，实际高度由原有组件容量决定，最高3022。没有改字体、删边、改processor像素限制，或自行绘图。4例无图按共同回退规则处理。三个固定例图已实际打开，标签、图例和方向可见；密集AIOPS-2022调用图仍有较多交叉边，不能据几何通过断言模型容易读懂。

在CPU内另外试算了全局共享表头/保留原位置，以及TSV列表示。固定三例前者增加约106–119个token，后者增加约648–739个token，均未采用。这些是构造探查，不是新模型实验、RCA结果或正式臂；没有根据排名调整格式。

因此，本次结论是：**已解决原来“连文本概览都装不下”的问题，但当前完整节点图的输入开销仍阻止共同视觉流程通过40%门槛。** 不能把文本达标写成完整方法达标，也不能把本轮结果写成视觉取证MRR失败。当前实现仍有进一步改进空间，本报告不声称已经证明所有无损表示均无法满足预算。

| 数据集 | 完整文本平均输入 | 选择阶段平均输入 | 最终阶段概览平均输入 | 乐观两轮输入＋512预留/F |

最后一列是 sum(t + 512 + m) / sum(F)，将每例都按最小完整包计算；它是预算诊断用的乐观值，**不是实际模型 input＋output 成本**。最终诊断输出没有发生，也没有计入该列。AegisLab 的总体平均低于 85%，不能替代逐病例 40% 首轮限制和至少 50% 适用率。

本计划同时要求保留全部既有实体摘要、统计和公共关系，再把完整概览传给最终诊断。即使把指标序列、AUX 向量与请求配对样本移入按需取回包，当前概览仍较长，重复传输占据了大部分两阶段预算。选择目录和提示也有开销。当前最小明细还允许选择已经在概览出现的短 Trace 记录，属于偏乐观的必要条件；没有借此宣称取回了新增诊断证据。

以固定 AIOPS-2022 病例 `INC-6E627662CA32` 为例：F=23,088，t=11,311，首轮比率 48.99%；为最终请求留下的预算仅 7,801，连未加入明细的概览 10,773 都容不下，最小完整明细请求为 10,923。这不是 40,960 上下文容量造成的错误：全体病例最大的完整文本输入＋8,192 为 33,969。

这一结论仅针对**当前编译方式、事实保留要求和冻结预算的组合**。它不证明所有两阶段方法不可能降本，也不证明视觉用于选择证据没有排名收益。改变概览内容、重复传输方式或预算属于新的设计决定，不能静默用于挽救本轮。

## 4. 实现修复与独立核对

CPU 阶段发现并修复了以下实现问题，随后才生成当前完整结果：

1. 旧拓扑辅助函数仅取 additional-component 账本，会遗漏完整文本 G 部分的公共关系。新编译器取完整 G、组件关系及请求父子关系的去重并集；保持方向、类型、操作事实，不改历史代码。
2. 配对样本实际字段是 `points`。已正确移入完整明细包，保留两阶段统计、总体数量和实际样本数。
3. 取回的组件记录保留原有嵌套 codec，不在中间层擅自展开为不同写法。
4. tools Python 缺少实际 processor 所需的 PyTorch，首轮 CPU 计数失败。改用已安装的 infer Python 并显式禁用 CUDA；没有安装新包、加载权重或启动服务。失败日志保留。

验证范围：
