# RQ1b2 answer-hidden compositional-complexity protocol — v1

## Status and relationship to the failed RQ1b gate

This is a separately registered, exposed-development mechanism study. It does
not alter, rerun, or reinterpret the valid negative result of
`rq1b_visops_independent_gate_v2`, and it does not refit that experiment's
operation router. The old mapping and gate incidents are permanently excluded
from rule discovery and confirmation in this successor.

The motivating diagnosis is specific. In the old benchmark, the model-visible
facts for `multi_hop_path` included the already-derived path, and the temporal
tasks included the already-derived onset or persistence scalar. Those tasks
therefore measured lookup and sorting more than graph or time-series reasoning.
Exact lookup remains an important negative control, but it cannot answer
whether a visual encoding helps when the answer must be composed from several
equal-information atomic facts.

## Registered question and hypotheses

> When the answer itself is hidden and must be derived from the same raw atomic
> facts, does visual utility increase with temporal or relational composition
> complexity?

The arms remain strictly paired:

- `T`: deterministic text serialization of the query facts;
- `V`: deterministic visual encoding of exactly the same query facts;
- `H`: exact prompt-fragment concatenation `A_visual + B_text`, with no
  hybrid-only instruction, fact, or rewrite.

Primary hypotheses for Gemma-4-26B-A4B-it are evaluated on the paired raw
temporal-onset family. The topology family is a registered secondary analysis
because label-blind preparation established that three-to-five-hop unique paths
exist only in the AegisLab development graphs, so pooling it into a three-
dataset endpoint would confound complexity with dataset/task mix.

1. `P1`: on high-complexity answer-hidden temporal tasks, `V-T >= +0.10` case-macro
   accuracy with two-sided Pratt-Wilcoxon `p < 0.05`;
2. `P2`: the paired complexity interaction
   `(V-T)_high - (V-T)_low >= +0.10`, with two-sided Pratt-Wilcoxon `p < 0.05`;
3. `P3`: a temporal rule fixed before the independent gate (`low -> T`, `high -> V`)
   exceeds the best single fixed arm by at least `+0.05`, with two-sided
   Pratt-Wilcoxon `p < 0.05`.

`H-T`, `H-V`, topology/path results, tokens, latency, repairs, breaks, and
answer-set errors are secondary. Qwen3.6-27B is an architecture control and uses the same tasks,
thresholds, and frozen complexity rule. A Gemma-only success is explicitly
architecture-specific.

## Task construction

All truth is generated by a frozen label-blind algorithm from the facts in the
query. The derived answer and any equivalent shortcut are evaluator-private.
Every supporting input fact is visible in T, V, and H, but none of the arms may
contain a `multi_hop_path`, precomputed answer, highlighted winning entity,
precomputed onset, precomputed persistence, or answer-bearing color/position.

The first implementation contains three paired task families:

1. **Raw temporal onset.** Low complexity contains four metric series and high
   complexity contains up to twelve. Each series exposes the same relative-bin
   values and missingness mask. A public, fixed robust-change rule defines
   anomalous bins and sustained onset. The private answer is the earliest panel
   or complete tie set. The renderer plots the raw normalized series without
   highlighting the answer; text contains the identical normalized bin facts.
   The baseline is the median of the first 16 source bins, scale is the maximum
   of `1.4826*MAD`, one percent of the absolute baseline, and `1e-9`; the 64
   source bins are median-aggregated into 16 deterministic blocks and rounded
   to one decimal. Displayed robust-z is symmetrically winsorized at `+/-99.9`
   before all three arms are compiled. This cap is above the public `|z|>=3`
   threshold and preserves sign, so it cannot change any private onset answer;
   it prevents near-zero baselines from producing unreadable values such as
   `5e8`.
2. **Directed shortest path.** Only concrete caller-to-callee edges are visible.
   Low complexity uses a two-hop target with bounded distractors; high
   complexity uses a three-to-five-hop target and more distractor edges when
   the observed graph supports it. The shortest path is derived privately and
   is never serialized or highlighted. Ambiguous shortest paths are omitted by
   a frozen, label-blind eligibility rule.
3. **Exact lookup control.** A bounded single-fact lookup is retained to verify
   that any gain is complexity-dependent rather than universal superiority of
   the visual arm.

Low and high variants are constructed from the same incident where supported.
Operation eligibility may inspect only telemetry structure and missingness,
never root-cause labels, fault types, model outcomes, or private case metadata.
Unsupported tasks are omitted before inference and never replaced after an
outcome is observed.

The frozen development qualification requires paired low/high temporal tasks
for at least 75 of 90 incidents and at least 20 incidents in every dataset. It
requires the exact-lookup control for all 90 incidents. Relational low/high
yield is reported, but the absence of high-hop graphs outside AegisLab is a
data property rather than an infrastructure exclusion; topology is not pooled
into P1-P3 and cannot carry the promotion decision.

## Information and prompt parity

For every query, the fact-ID inventory and public value hash must be identical
across T, V, and H. The question, derivation rule, edge semantics, relative-time
semantics, output schema, system prompt, and decoding contract are common. H
must be byte/part exact `A+B`. A visual primitive must map to every supplied
fact, and no primitive may map to an evaluator-private answer.

This is equal information within a task, not equal information across low and
high complexity: the latter intentionally changes task size. The inferential
quantity is the within-level paired representation effect and its paired
difference across levels.

## Data and one-way execution stages

Only cases explicitly marked `exposed`, `eligible`, and
`rq1_exposed_development` in `exposure_ledger_v2.json` may be used. All old RQ1b
mapping/gate cases, smoke cases, RE2, heldout, reserve, and unknown cases are
excluded.

- **Development:** 90 new exposed incidents, 30 per AegisLab, AIOPS-2022, and
  AIOPS-2025, selected outcome-blind with
  `SHA256("42:rq1b2:development:<dataset>:<private_case_id>")`.
- **Independent gate:** 150 additional disjoint exposed incidents, 50 per
  dataset, selected after removing all prior RQ1b and RQ1b2-development cases
  with `SHA256("42:rq1b2:gate:<dataset>:<private_case_id>")`.

Roster membership is frozen before preparing real cases. Development may tune
the task renderer and public derivation wording, but not by reading root-cause
labels. After qualification, the task compiler, renderer, prompt, scorer, and
complexity rule are frozen. Gate outcomes cannot be used to revise them.

The development cell runs Gemma only. It authorizes the independent gate only
if parity and perception qualifications pass, temporal high-complexity
`V-T >= +0.05`, the paired temporal complexity interaction is positive, and
visual repairs outnumber visual breaks. If it fails, this mechanism stops
without Qwen or gate inference. If it
passes, the complete independent gate is run for Gemma and Qwen regardless of
the emerging Qwen direction.

## Gate thresholds and statistical basis

The opaque incident is the inferential unit. Query correctness is averaged
within incident and complexity level before comparisons; queries are never
treated as independent samples. Zeros remain in the two-sided Pratt-Wilcoxon
test. Dataset effects are reported separately.

For the 150-incident independent gate, the normal paired-test approximation is

```text
MDE = (1.96 + 0.84) * paired_sd / sqrt(150).
```

The prior representation-effect SD of 0.36 gives an MDE near 0.082; a
conservative SD of 0.50 gives 0.114. The practical `+0.10` thresholds therefore
sit near the power boundary and require an effect large enough to matter, not
merely a small p-value. The routed-versus-best threshold is `+0.05` because it
measures an aggregate policy improvement after the stronger mechanism checks
have already passed. Effects with the right sign but below the attainable MDE
are reported as inconclusive, not as evidence of absence.

The primary Gemma gate passes only if temporal P1-P3 all pass, at least two of three
dataset-level temporal high-complexity `V-T` effects are positive, no dataset is at or
below `-0.10`, parse rate is at least 0.95 per arm, paired whole-incident
infrastructure exclusion is no more than 5%, and all leakage, fact-parity,
determinism, perception, truncation, and accounting gates pass. No confidence
interval is reported under the project rule.

## Consequences

A pass authorizes design of a new complexity-aware RQ1c access policy; it does
not resurrect the rejected old operation router and is not itself a heldout RCA
efficacy claim. P1 without P2 means visual value is not shown to scale with
complexity. P2 without P1 means relative scaling exists but the high-complexity
visual arm is not practically useful. Failure stops this mechanism and leaves
RQ1c/RQ1d blocked.
