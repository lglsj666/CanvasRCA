# RQ4.7 experimental contract

Authority: [approved plan](../../../docs/experiment_plans/RQ4_7_Source_Bound_Visual_Workspace_Plan_2026-10-20.md).
This implementation session stops after static source checks. No runtime permission is issued.

| Condition | Selection | Workspace | Final response |
|---|---|---|---|
| S_COMPARE | deterministic CPU | complete, compatible comparison | original ranking envelope |
| S_GROUND | same CPU selection and image | same pixels | ≤3 source-bound observations, then ranking |
| S_REASON | same CPU selection and image | same pixels | ≤3 short notes, then ranking |
| M_CROP | shared fresh action call | literal crop | original ranking envelope |
| M_CLOSED | same committed action | complete original source | original ranking envelope |
| M_COMPARE | same committed action | complete, compatible comparison | original ranking envelope |

S_GROUND and M_COMPARE are the two preselected methods. All new incident evidence
is in images generated by registered unified-renderer operations. A two-call
exception is authorized for this experiment only. Neither prior results nor QA
answers enter either model stage. Grounded assertions are audited after the answer;
the host neither corrects them nor reranks candidates.

Development: 220 exposed cases; maximum 2,110 actual nodes, including the shared
action, independent QA, interventions and full repeats. Conditional independent
validation: at most 450 calls, only after both source/exposure and candidate-specific
engineering gates. Smoke: at most 18 calls in one 15-minute logical window.
Recovery reserve: 122 initiated attempts. Grand ceiling: 2,700.

Malformed JSON or an invalid top-level plan is an empty plan. Within a structurally
valid list, invalid actions are rejected independently; no coordinates or identifiers
are repaired. Geometry must identify exactly one source panel. Whole-group capacity
admission is common across M controls. Oversized/incompatible groups do not acquire
new facts or trigger smaller fonts. A real empty action plan retains the full overview.
An infrastructure/rendering error is never converted into a model-invalid empty plan.

Private evaluation contexts are separate files. Strict ranking and tolerant sensitivity
use `scorer`; duplicate/unknown candidates remain misses at their original positions.
An auxiliary observation-format error is recorded separately from ranking validity.

No proposed method is automatically adopted by maximizing observed MRR.
