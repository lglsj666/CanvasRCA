# DD-RQ3-SEARCH-14 — Compact public membership and diagnostic contrasts

Date: 2026-09-12. Status: provisional, train-only development; not promoted.

## Evidence and decision

The 24-call SEARCH-13 batch completed without infrastructure or schema errors.
Adding every host/pod relationship worsened the paired twelve-case result.
Do not promote that all-hosting condition. The exhaustive candidate universe
remains prompt-only; relationships between displayed entities are evidence,
not a candidate-list image panel. Private roots remain evaluator-only.

An offline train audit found that service-owned traces and pod-owned metrics
can refer to the same public name family, but their independent anonymous IDs
hide this association. Several AIOPS2025 labels already accept service-level
answers, so this is NOT a claim that the scorer makes those cases impossible.
Expose the inherited public pod-name projection as a typed group relation,
not a newly inferred call edge, host location, or proof of which replica failed.
Only relationships incident to displayed diagnostic owners enter the image.

Compare ranked membership with cross-source membership on the same twelve
registered training cases (six per AIOPS dataset), 24 Solver calls maximum.
No attention, Composer call, validation, eval, training or dataset rewrite.
Both conditions use the corrected public IDs, labeled trace axis, same static
reading guide, exhaustive text candidates, and non-thinking request profile.
This isolates the two registered selection policies with their corresponding
local relationship context; it is not an equal-information representation test.

Cross-source selection keeps eight metric slots. Half first seek metrics of
displayed trace/log owners or their public name-family neighbors; the rest
search globally. Greedy selection prefers previously uncovered entity/family
pairs, directly interpretable resource/latency/error gauges, and bounded mean
change weighted by native MET-Z magnitude. Inventory/capacity and cumulative
counter series remain eligible but lower priority. All source values, units,
time windows and statistics remain unchanged. Ranking uses public data only;
it is a heuristic to test, not a pre-validated RCA method.

services, actual selection changes, candidate preservation, source/fact
binding, deterministic PNG, complete relationship rendering and prompt-only
candidates. Check both datasets' actual images before registering live work.

the full-data targets. Preserve all earlier RQ code, pools and results.

generic clock-gauge tests move beside their shared helper. This changes test
ownership only, not arithmetic, training, selection or the six-module limit.
