# Research statement

Does removing outside-domain image positions help because of the retained positions, the shorter sequence, or attention allocation? Can a small number of aggregated outside-domain features retain useful context while leaving all registered evidence unchanged? Do sample glyphs matter when exact sample numerals no longer duplicate them?

This is exposed-development research, not an untouched validation. P_DOMAIN−P_FULL = approximately +0.0428 from RQ4.9 remains a useful signal with its original nonsignificant Holm result. We do not re-test that historical contrast in a smaller family. Hybrid is explicitly authorized for this round; every RCA method makes one model call. No training, new model, agentic step, new telemetry or automatic winner promotion.

A includes numerical text as well as identity/unit/statistic text. O denotes positions outside renderer evidence support, not necessarily semantically empty encoded features. Evidence omission, pixel omission, token deletion, embedding fusion and attention redistribution are distinct interventions.
