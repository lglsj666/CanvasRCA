## Original dashboard examples

The five `dashboard_*.png` files are verified byte-identical hard links to actual
unified-renderer inputs. Each arm appears once, all for AegisLab incident
`INC-7FCA48559A2E`. They illustrate input design, not case-level performance.

- MARGINAL_FIVE: the small image; accompanying full diagnostic text is not shown.
- A_UNIFORM_E50: the complete overview before feature-token selection.
- SEM: the shared complete image; encoder groups are not visible in the PNG.
- X_SRP: the compact canvas used by the combined method's formal request.
- SOURCE_ZOOM: the local atlas only; its request also contains the U overview.

Open the original PNG to inspect dense labels. No crops, beautification, masking
or rerendering were applied. The report's embedded display may scale the image.

An original RQ1.1 TPV dashboard was not verified in the retained report assets
after the historical cleanup. TPV is represented by its input-contract schematic
and actual retained results, not by a newly reconstructed image labeled as an
original model input. Figures 6–10 remain the five verified dashboard examples.

`figure_data.json` records numerical values, original paths, dimensions and SHA-256
hashes. Dashboard links intentionally share immutable bytes with the originals;
do not edit them in place.

## Rebuild

From the directory containing the Markdown report:

```bash
/home/lglsj/CanvasRCA/venvs/tools/bin/python CanvasRCA_Project_Review_2026-10-12_assets/build_figures.py
```

This reads completed result tables, recreates report charts and verifies the
dashboard exemplars. It does not start inference, recompute scores, or invoke
the dashboard renderer. Keep this directory beside the Markdown report when
sharing it so that its relative image links work.

## Portable references and PDF

The `references/` directory contains a snapshot of every local file directly
cited by the meeting report, the embedded figures needed to display those cited
Markdown reports, and the numerical/image dependencies of `build_figures.py`.
`reference_manifest.json` records each original project path, size and SHA-256.
The meeting report links to these snapshots, so its direct citations and figures
remain available on Windows without a WSL checkout. This is a report package,
not a copy of all historical experiment artifacts or every secondary link in the
historical reports. Public paper links still refer to the original websites.

`build_figures.py` uses the reference snapshot when it is present. Identical
dashboard dependency copies are hard links within the WSL package; their bytes
are not modified. Historical source documents elsewhere in the project remain
in their original locations.

The adjacent PDF is generated by `build_pdf.py` and `report_pdf.css`. It includes
section bookmarks, page numbers, vector analytical charts and the full-resolution
original dashboard images. Dense dashboards can be magnified in the PDF or
opened from their original PNG links. Local PDF file links are relative to the
report folder; some PDF viewers require permission to open local attachments.

PDF regeneration requires Python packages `markdown`, `beautifulsoup4`,
`weasyprint` and `pymupdf`, plus WeasyPrint's system font/rendering libraries:

```bash
python CanvasRCA_Project_Review_2026-10-12_assets/build_pdf.py
```
