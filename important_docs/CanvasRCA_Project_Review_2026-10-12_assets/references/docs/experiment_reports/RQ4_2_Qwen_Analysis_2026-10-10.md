# RQ4.2 完整结果与分析：基于证据来源的视觉编码分区

日期：2026-10-10（America/Toronto）。状态：**正式实验完成，完整性审计通过；预选 SEM 未达到采用目标。** 本轮为已暴露开发病例上的方法实验，不是独立确认测试。

## 1. 主要结论

本轮没有超过历史最强纯视觉，也没有接近强文本。五个新条件中 NATIVE4 的 MRR 最高，为 **0.3235**；预选 SEM 为 **0.3084**，GEOM 为 **0.3088**，FULL 为 **0.2841**。历史 A_UNIFORM_E50 为 **0.3517**，强文本 T_FULL 为 **0.4846**，混合锚点 MARGINAL_FIVE 为 **0.5054**。

可以保留三项实际收获：完整视觉方案的无效输出大幅减少；新 FULL 相对历史 V_FULL 的 MRR 点估计提高约 0.0632；SEM 扩大了 Top-5 命中范围，并改善部分阶段比较 QA。但**正确来源分组没有比简单空间分组带来总体 MRR 改善**，也未超过原生四图。不能把这些局部改善写成预选方法已成功。

成本方面，SEM 比强文本减少约 **24.02%** 的 input＋output token，但仍约为均匀剪枝的 **2.89 倍**。按逻辑位置汇总，SEM 连续冷路径平均 **24.84 秒**，比 FULL 快约 **3.93%**，却比历史强文本在线耗时高约 **12.23%**；排除引用位置后，SEM 的真实调用均值为 **24.90 秒**。历史时延只是协议登记的保守跨时期工程参照，不是同期等负载冷启动比较。

本轮最有决策价值的结论是：**分组 attention 的工程实现可行，但把可见关系的切边权重降下来，不等于模型能够更正确地定位根因。** 继续优化当前纯视觉强基线，比继续调整 SEM 分区层数更符合后续主线。

SEM/SHAM 使用用户授权的 v4 best-prefix 算法：从空间分区出发，允许一轮内暂时不改善的移动，最后只提交严格改善的最佳前缀。最多 8 轮、100 次提交移动，来源单元和 2×2 merger 邻域完整，各组容量相同，累计背景移动不超过 5%。v1–v3 资格失败保留，未降低阈值；v4 SEM 准入为 57/60、56/60、71/100，SHAM 为 56/60、56/60、90/100。准入说明干预足够不同，不表示它对诊断有帮助。

模型为本地 Qwen3.8-27B（checkpoint 实现架构 Qwen3_5），BF16、SDPA、HF 单进程单请求，40960 context、8192 输出上限、显存参数 0.75。同病例五臂 seed=42。RCA 排名前缀 greedy，reason/confidence 按 temperature=1、top_p=.95、top_k=0；QA 使用单独 JSON 接口，不继承 RCA 排名要求。

历史对照全部复用，不重新推理：

- **T_FULL、A_UNIFORM_E50、V_FULL** 来自 RQ4.1 的正式 development 主矩阵，同一 220 身份及评分口径。原配方同样包含 greedy 排名前缀，但 seed 为历史病例种子，视觉提示/布局也与本轮不同；用于系统对照，不能把 FULL−V_FULL 全部归因于一个组件。

## 6. 干预确实改变了输入计算，但没有形成稳定排名增益

220 例中 184 例达到 SEM 的联合干预门槛，36 例未达到，全部保留分母。即使只作事后诊断查看 184 个门槛通过病例，SEM MRR 0.3130 仍略低于 GEOM 0.3149；这不是采用门槛，也不重新选择这些病例运行。

卡片加权变化率、前景加权变化率、真实关系切边降低量与 SEM−GEOM 的 RR 改变量的 Spearman ρ 分别约 0.035、0.076、0.048。探索性描述没有显示强度越大、排名越好的明显单调关系。CPU 门槛排除了“根本没改多少”这一简单解释，不能代替下游收益验证。

相同的图像不意味着相同的编码计算；反过来，改变计算也不保证改变排名。这里的“相同排名”明确是输出比较：

理论上早期四组 attention 将登记的二次项运算量缩到约 0.3611，并没有带来 63.9% 的端到端加速。实测只支持 SEM 冷时延相对 FULL 下降约 3.93%。本轮正式 usage **没有单独记录视觉编码、prefill、decode 的计时**，无法把这 3.93% 分解为编码器、输出长度或其他步骤的贡献；不能补写出不存在的计时。峰值 allocated memory 是进程累计最大值，也不是每臂独立峰值。没有实际货币价格、GPU active time 或能耗计量。

## 9. Attention：测到了什么，不能推出什么

采集复用固定 60 例的主调用及 59 例 QA。实际 534 个独立摘要，覆盖 536 个逻辑位置（2 个位置引用相同计算的原摘要）。文本 full-attention layer index=3，只记录最后一个 prompt query 与第一个 decode query，全头平均；**不是视觉编码器 0–22 层的 attention**，也没有中后期排名 token 或逐头轨迹。

图像区域以真实 32px merged cell 与 DOM 绑定框的最大相交面积分类。`header` 只对应最顶端页眉行；组件标题、作用域文字以及未匹配专门数值类别的 detail 字段并入 `labels`。`text:instructions` 包含静态指令、模板和特殊 token；不能把它等同于纯自然语言指令。区域是粗粒度归类，不是每个像素或数值 token 的完美归属。

下面为同一 60 例主 RCA 的平均 attention 质量占比，引用位置按逻辑方法记账：

| Arm | prompt 文本 | prompt 图像 | decode 文本 | decode 图像 | 页眉占图像 attention（prompt） |
| --- | --- | --- | --- | --- | --- |
| FULL | 89.75% | 10.25% | 78.07% | 18.94% | 5.35% |
| GEOM | 85.65% | 14.35% | 72.44% | 25.03% | 8.55% |
| SEM | 88.18% | 11.82% | 75.22% | 22.09% | 6.49% |
| SHAM | 88.18% | 11.82% | 75.18% | 22.13% | 6.59% |
| NATIVE4 | 84.61% | 15.39% | 72.37% | 24.96% | 9.24% |

可见：图像获得的 attention 会随编码路径改变，但更高图像 attention 不等于更高诊断分数。SEM 与 SHAM 的这些粗粒度质量分配非常接近，不能据此判定模型已利用正确关系。图像内部主要质量仍在 labels；页眉有高于其图像面积份额的注意倾向，但只占图像质量约 5%–9%，并未“占据大多数”。

因此，本轮没有直接复现或证实“attention 全集中在 dashboard 标题”。早期实验的标题类别与本轮页眉定义也不同，不能跨口径画一条趋势线。高文本权重可能涉及任务、模板及 query 位置；本轮没有删标题、删指令、删 sink token 的干预，不能把高权重解释为有害 sink，或把低权重解释为模型完全没用图像。

**结论：本候选结束，不采用 SEM，不继续自动搜索分组层数、阈值或重连种子。** NATIVE4 是本轮最高点估计，不能事后改称预选方法，且它仍未胜过更便宜的历史 A_UNIFORM_E50。

下一阶段建议以当前完成实验中最强的纯视觉 `A_UNIFORM_E50` 为优化起点，按用户的软建议给约三个 arm 探索性能/成本改进，其余有限条件检验假设和反直觉现象。具体候选应先避免与历史重复，再单独设计与登记。本报告不启动下一轮，也不把“新布局＋均匀剪枝”的未测组合预先视为成功。

值得带走的机制问题是：为什么候选合法性、部分 QA 和 Top-5 覆盖改善，仍不能转化为首选与 MRR 改善？应围绕能推动强纯视觉方法的实体绑定、证据取舍和排名决策设计有限干预，而不是以 QA 或 attention 的单项改善替代诊断目标。历史 T_FULL 与 MARGINAL_FIVE 持续保留为对照，兼容回答直接复用。

## 13. 有效性与尚未回答的问题

- 220 例是多轮已暴露开发数据；没有本轮冻结后的独立确认集。即使一个臂在这里胜出，也不能直接宣称泛化或超越 SOTA。
- 来源关系优化目标是工程代理，不是已知因果机制。SHAM 保持类型/度数却并非真实关系的全面等难度替身；阴性比较只限定本轮归因。
- 主要比较事件组单位193，其中A22仅33组；病例均值与组均值权重不同。小故障类型层有的仅1–3例，故障分层仅描述，不按其事后选最佳方法。
- QA仅59例、350题，题目局限在两张Trace卡和关系；未覆盖全部M/R/L/G。QA准确率差与RR差的弱相关不证明相互独立。
- Attention只观察一个文本层的两个位置，分类包含混合字段，不能用于直接定位视觉编码器内部错误或推断token删除的收益。
- 没有本轮独立RCA重复，没有正式逐层/编码/生成计时；当前不能做比已有测量更强的稳定性或速度归因。
- 历史混合/文本系统比较保留其原始配方与时期；共同病例和评分不等于同事实可见性与同生成协议。当前五个新视觉臂之间的受控比较更直接。
