# RQ4.1 最终分析：纯视觉比较依赖编码、诊断稳定性与 attention

日期：2026-10-09。实验：`comparison_coding_v1`；正式结果目录：`formal_v28`；最终运行依赖冻结：v29。研究范围为 **220 个已暴露开发病例**，不包含独立确认结果。本文是完成后的正式分析，取代聊天中的临时进度和临时指标；历史协议与原始结果保留。

## 1. 结论与决策

**本轮完整跑完，但预选 CVC_E50 没有实现“纯视觉超过强文本、实际部署成本不增加”的目标。** 它将平均 input＋output 从 T_FULL 的 22,243.9 降到 5,853.2 token（−73.69%），但 MRR 从 **0.4846 降到 0.3332**。三个数据集都下降；不能用压缩率掩盖排名损失，也不能把 token 降幅直接称为运行时间降幅。

这轮仍得到几项具体结果：

1. **同一完整 dashboard，保留全部视觉 token 的结果比多种剪枝结果更差。** V_FULL MRR 0.2209，CVC_E50 0.3332，均匀空间覆盖 A_UNIFORM_E50 0.3517。说明本实现中“保留更多视觉 token”没有带来更好的诊断；但正确比较依赖的独有贡献未建立，不能把一般剪枝收益全部归于 CVC。
2. **纯视觉诊断明显依赖空间位置。** 事实不变的位置干预使 CVC 和 UNARY 各有 47/90（52.22%）首选翻转；相应独立重复均为 0/90。两项注册检验的 v11 Holm p 均为 7.47×10⁻¹³。这是本轮最清楚的机制结果。翻转不等于必然降分。
3. **存在真实的输出身份/唯一性损失，但这不是全部性能差距。** CVC 12/220、V_FULL 33/220 无效；GPRUNE 220/220 无效。保留原排名槽位的事后宽容重评分，CVC 也只有 0.3544，仍明显低于强文本。
4. **QA 支线没有完成原定的“读取—绑定—比较—诊断”解释。** 严格联合分数全部为零，且文本 QA 混入了 RCA 任务指令，87 份中 73 份仍含根因排名字段。零方差使 QA–RCA 相关性不可估计，不能报告成“相关性为零”或再次证实“读懂与诊断无关”。
5. **标题区域出现相对较高的 attention 密度，但没有证明有害 attention sink。** 测量仅覆盖一个 full-attention 层、两个起始 query；标题包含页眉及全部组件标题。CVC 减少标题区域占比、提高图像/观测区域 attention 质量，同时 MRR 高于 V_FULL，这是共变观察，不是因果解释。

按登记结束当前 CVC 候选，不自动采用事后最高分的均匀覆盖臂，不自动追加调用或开启独立确认。保留“压缩可改善当前视觉系统”“空间位置强扰动”“token 成本与运行时间脱节”这三条有实际价值的开发发现；不能把本轮写成纯视觉 RCA 已成功。

**E50 不是保留整张图 50% 的 token。** 当前定义为：全部锚点 A ＋可选证据支持 E 的 50%。E25/E75 同理。视觉编码器仍对原图运行，后续才选择/剪枝；层内方法在剪枝前还运行完整 token 的前置 decoder 层。可选支持预算和完整图像 token 比例不可混用。

本轮所有视觉方法都只通过 dashboard 提供诊断事实；图外是静态任务/读图/输出说明。完整文本与像素图是系统比较：共享公共来源不意味着像素与精确文本的信息可逆性完全相同。不能把全部差异称为“相同最终输入的纯视觉因果效应”。

### 3.2 实际模型配方与后端

使用本地 Qwen3.8-27B（本地 checkpoint 的实现架构为 Qwen3_5）、BF16、40960 context、8192 输出上限、显存利用率 0.75。正式配方采用已授权的 v25：五个 services 的排名前缀使用 greedy，后续 reason/confidence 按登记采样；独立重复改变 seed。静态数字格式约束不含病例候选白名单，五个 ID 的候选身份和唯一性由宿主完成后校验。

主 HF 阶段 batch=1；T_NATIVE 在后一时间块以并发 36 运行。该执行修订在正式开始前登记。**native 请求等待时延、HF 单请求时延和 native 批处理吞吐不是同一种成本。** 原始方案中的旧批次/统计/资源条款，以正式启动及后续无语义种子修复记录为准。

协议与修订：[原计划](../../RQs/RQ4_1/descriptions/RQ4_1_experiments.md)、[E 预算](../../RQs/RQ4_1/descriptions/RQ4_1_Evidence_Budget_Investigation_2026-10-06.md)、[排名前缀配方](../../RQs/RQ4_1/descriptions/RQ4_1_Ranking_Prefix_Decoder_2026-10-07.md)、[正式启动](../../RQs/RQ4_1/results/comparison_coding_v1/logs/formal_launch_v28_2026-10-07.md)、[native 修复](../../RQs/RQ4_1/descriptions/RQ4_1_Native_Seed_Repair_2026-10-09.md)。

### 4.3 哪些故障类型丢分：事后描述

不是所有类型都同向。AIOPS-2022 的容器CPU负载6例，CVC为0.7222、T_FULL为0.4444；但容器网络资源包损坏6例为0.1444/0.5333。AIOPS-2025 的pod failure 11例为0.1818/0.0485，CPU stress 6例却为0.3750/0.8333。AegisLab 的HTTPResponseReplaceCode 13例为0.4667/0.2744，JVMMemoryStress 14例却从文本0.8929降到CVC0.3440；后者贡献约7.68个RR总和损失，是该集净18.42个RR损失的约41.7%。这表明不能用“视觉更擅长CPU故障”一类跨集口号总结。

这些类型是在结果后按已有私有评价标签作描述，不进入模型、不用于选择新路由，也不追加小样本显著性检验。完整类型表保留n，附录只展开n≥5的组；更小组不能承载泛化结论。

## 5. 预注册统计与效应量

### 5.1 采用哪套检验

执行前用户明确选择了保守 **v11：固定有界事件组均值混合检验**。分析对象为病例加权的配对均值差；193 个事件组内允许依赖，组间独立是假设，不是由组数自动证明。193 组的大小为：178×1、6×2、7×3、1×4、1×5。

实现将每组差值求和，以最大组大小统一缩放，使用冻结的 32 个正/负投注比例计算平均乘积 E，取 `min(1, 1/E)` 为双侧 p。差值保留 12 位，各登记族分别 Holm 校正，α=0.05，不报告 CI。该方法不同于后来根据结果选择的普通 t 检验；本次没有改检验。

此前校准记录已经说明其检出能力很低，用户接受这一取舍。压力测试中零均值误报率上限 QA 0.75%、development 0.35%；名义 +0.03 偏移下最好的未校正检出率也只有 QA 2.15%、development 0.40%（仅指登记压力分布，不是本数据的真实功效估计）。因此不显著不能解释为等效或证明无贡献。

Pratt-zero 双侧 Wilcoxon（病例级和事件组均值级）及配对 dz 仅作敏感性描述，表内标 †；它们不能替代 v11 达成主要判定。组级 dz 和所有完整数值在 CSV 中。规则来源：[v11 决策](../../RQs/RQ4_1/descriptions/RQ4_1_Statistics_V11_Adoption_2026-10-07.md)、[有效统计配置](../../RQs/RQ4_1/configs/statistics_active_v11.json)。

### 7.2 启动前修复为何没有消灭正式失效

smoke 证明的是有限样例上的调用/接口可执行性，不保证 220 例所有数字身份的可靠复制。静态数字语法只保证三至五位格式，不知道哪个数字属于当前 inventory，也不保证五个 ID 不重复。排名前缀 greedy 消除了随机排名采样，却不会纠正一个确定性错误数字。SCOPE/S2PRUNE 的保护修订保留了更多身份上下文，但正式无效率仍分别 25.91%/28.18%。这是资格覆盖与实际泛化的差距，应如实保留。

## 9. 独立重复与视觉干预

### 9.1 重复的究竟是什么

T_FULL、V_FULL、UNARY_E50、CVC_E50 各在固定 90 例（每集 30）重新调用一次；文本与图形内容相同，调用身份/seed 独立。全部 **360 对的五候选排序完全相同**，RR 也完全相同；但 **360 对完整回答及 reason 均不同**。所以这里的“相同”是排名输出相同，不是完整输出相同，也不是复用了旧回答。

这是 greedy 排名前缀下的稳定性结果；后面的解释仍采样，不能泛化成原温度下任意输出都稳定。该子集 CVC MRR 0.3030、T_FULL 0.5233、UNARY 0.2648、V_FULL 0.1804；完整方法重复相对强文本仍为负，未通过重复方向门槛。

POSITION 保留公共事实，只改变画布组织/位置，随后按原流程重新编码和选择。因此它是整个位置敏感工作流的干预，不是固定特征条件下某个位置编码参数的纯效应。CVC 和 UNARY 相对各自独立重复的额外翻转率均为 +52.22 个百分点，v11 两项 Holm p=7.47×10⁻¹³。

CVC 的 MRR 由 0.3030 降到 0.2815，UNARY 由 0.2648 微升至 0.2678。**大量首选变化与均值分数变化是不同现象**：不能从翻转率推导同幅度性能退化。它说明模型使用的证据优先级/绑定容易随表示位置改变。

BINDING、OPERAND、IRRELEVANT 是登记的事实/图元扰动，不能沿用原根因标签给“新世界”评分。CVC 的 IRRELEVANT 翻转 17/87，OPERAND 10/87，仅作描述，未登记的二者优劣检验不在此追加；不宣称无关信息一定比真实操作数更重要。

## 10. QA：这次没有可靠回答“读懂是否改善诊断”

### 10.1 原注册分数

每个适用病例两组题块，每块分别评估 Read（双值）、Bind（双实体/操作/单位/阶段）、Compare（大小方向）；Joint 要求三者同时正确。以病例为分析单位，不把两块或字段当独立病例。90 登记病例中 87 适用，三个数据集适用数见附表。

| --- | --- | --- | --- | --- | --- | --- |
| CVC_E50 | 87/174 | 1.72% | 0.00% | 37.36% | 0.00% | 3 |
| T_FULL | 87/174 | 10.34% | 0.00% | 10.92% | 0.00% | 18 |
| UNARY_E50 | 87/174 | 1.15% | 0.00% | 35.63% | 0.00% | 2 |

### 10.2 发现了任务接口混用，不应掩盖

核对实际送入模型的提示和完整输出后：

| Arm | 保留 identify root cause 指令 | 返回 services 字段 | 返回恰好两个 blocks |
| --- | --- | --- | --- |
| CVC_E50 | 0 | 0 | 81 |
| T_FULL | 87 | 73 | 23 |
| UNARY_E50 | 0 | 0 | 80 |
| V_FULL | 0 | 0 | 77 |

T_FULL 的 QA 提示沿用了完整 RCA 任务和 services 输出要求，末尾再追加 QA，形成冲突。73/87 份返回 services 字段（可能与 blocks 共存，表列不是互斥类别）。因此文本 QA 不构成干净的同任务模态参照。视觉 QA 虽无这项 RCA 指令混用，仍出现目标读错、实体/操作错绑和回答字段缺失。

Bind 的评分对每侧四个字段要求完全匹配；数值 ID 与字符串、阶段大小写等存在表面格式错误。本次仅作事后诊断，将这些格式和 `us/µs` 的表面拼写正规化，**仍没有任何题块双侧完整绑定正确，Joint 仍全部为零**。所以不能简单把失败归结为严格字符串匹配；真实目标与操作数关联错误也存在。原分数不修改。

例如 `INC-FBCBAA98002C` 的 CVC QA，第一块应读取 service546 对应操作的 reference/current span count **49/18**，却回答 **15161.79/9136.02**，并绑定到 service596 的耗时。第二块应为 count **985/3363**，却回答其他耗时值。部分大小方向偶然一致，不是对目标事实的准确读取。

**结论：本次 QA 支线存在有效性限制，不能用它解释主 RCA 改善或退化，也不能宣称旧的 QA–RCA 脱节问题已经解明。** 本轮不在看到结果后修提示重答；后续若继续该问题，必须先修复独立 QA 的任务接口和目标可定位性，再开展预先登记的小规模验证。

## 11. Attention：实际采集范围、结果及能支持的结论

### 11.1 不是整段推理的 attention

共 **801 份**：T_FULL、V_FULL、CVC_E50 三条件各有 90 个原始 RCA、90 个重复、87 个 QA。只采第一处 full-attention 层（**layer index 3**）的全头平均，且每调用只有 **最后一个 prompt query、第一步 decode query** 两个注册位置。没有逐层、逐头、完整输出序列或中后段排名 token 的 attention，也没有 UNARY/REWIRED 的同类测量。

记录已按实际 processor 几何及保留 token 索引核对。图像区域分 title、relations、labels、observations、other、mixed；mixed 是几何语义区域重叠，不强行唯一归属。`title` 同时含全局页眉与所有组件标题。`text:instructions` 含非图像 prompt/template/特殊 token，不只是自然语言；T_FULL 的文本桶还含诊断证据，所以不能把其文本 attention 和视觉静态指令直接作同语义比较。

下面只比较同一固定 90 例原始 RCA，避免混合 QA、重复和诊断任务。质量（mass）是某类 key 的 attention 权重和；密度是其每 token 权重相对该病例整幅图像平均值，再对病例平均。不是用原图像素面积直接相除。

| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| prompt末位 | V_FULL | 88.09% | 11.91% | 0.00% | 3.52% | 29.58% | 3.04× | 3.27% | 27.50% |
| prompt末位 | CVC_E50 | 85.99% | 14.01% | 0.00% | 2.24% | 16.06% | 2.41× | 5.45% | 38.96% |

![attention 聚合分区](../../RQs/RQ4_1/results/comparison_coding_v1/final_analysis_v1/figures/attention_regions.png)

在 prompt 末位，V_FULL 的标题区域占全部 key 权重 **3.52%**，占图像内部权重 **29.58%**，相对图像平均每 token 密度 **3.04 倍**；CVC 分别 **2.24%、16.06%、2.41 倍**。所以“标题比较集中”有观测支持，**“attention 全集中在 dashboard 总标题”则不符合本次记录的定义与数量**。

CVC 在同一子集只保留约 5,170 个图像 token，V_FULL 约 16,250；但 CVC 图像总质量从 11.91% 增为 14.01%，观测区域质量从 3.27% 增至 5.45%。这表明质量分配发生变化。不能说观测区域的单位 token 相对密度也必然上升：该归一化密度由约 0.865 降为 0.708，分母和保留区域组成同时改变。

文字/模板占 81%–88% 也不意味着“模型不看图”：这两个 query 位于输出 JSON 起始，而不是根因论证全文；格式指令和特殊 token 集中在此是可能解释之一。记录不支持区分格式需求、位置作用和真正有害 sink，更不支持仅凭权重就删除标题 token。

### 11.3 Attention 与诊断排名的关系

对 V_FULL/CVC、两个 query、六个图像区域，共 24 个探索性 Spearman 检验，Holm 后均未通过；最小未校正 p 约 **0.0523**（V_FULL 的 prompt 末位 relations mass，ρ≈0.205）。这里使用同例 RR，样本仅 90，相关性既不等于因果，也没有验证集预测检验。

CVC 相对 V_FULL 同时改变序列长度、图像 key 构成、空间表示和 attention 归一化；同时看到标题占比下降与 MRR 上升，不能证明前者导致后者。没有 UNARY/REWIRED 的 attention 记录，也无法用本轮数据解释 CVC 的正确依赖机制。没有保存逐 token 完整矩阵，因此本文只画真实的区域统计图，**不生成无法从记录支持的精细热力图**。

## 12. 定性案例：错误发生在哪一层

### 12.1 审查范围

结果完成后以固定 SHA-256 规则、每集前四例抽取 **12 个病例**，阅读 T_FULL、V_FULL、CVC_E50、A_UNIFORM_E50 共 **48 份 reason**。这不是运行前注册的抽样，标为事后定性检查。进一步定向核查六个病例中的数值/实体/阶段或候选合法性断言，并实际打开三个数据集的三张原始 dashboard。没有完成全体 4,840 份解释的逐句人工 grounding，不能估计总体“解释错误率”。自动正则扫描只作为定位线索，不计作人工确认错误。

### 12.3 密度和下采样是风险，不是已经确认的单一根因

220 张基础图宽均为8192，高2350–4622；processor 像素/上下文限制保持原值。按宽度缩放推算，原18px字体在实际处理网格上的等效尺寸约11.95–16.73px，三个数据集平均约12.32/12.79/12.49px。这个计算只是名义字体估计，不代表所有组件字号一致，也不能单凭聊天窗口缩略图判定模型必然看不清。

实际打开的三例包含约66–73个卡片，图中读值与实体关联负担很高。QA 中找错目标、解释中把纵轴量级/阶段/别的卡片读入当前证据，与这一风险一致，但没有独立的分辨率干预，不能写成密度已经被证明是全部退化原因。强文本单位错误也提醒我们，不应把所有推理缺陷都归咎于视觉。

## 14. 有效性限制与按登记收官

1. **数据曝光**：全部220例用于方法开发，不能称为未见测试。独立确认名册在正式前已登记不运行；没有把未用预算自动分给更多实验。
2. **统计功效与独立性**：v11已接受保守低功效，组间独立仍是前提；不能把不显著等同于无效应或等效。Pratt仅敏感性。
3. **干预强度**：CVC/REWIRED实际mask高度重合；支持代理饱和，限制正确依赖的机制鉴别力。
4. **模态和数值精度**：精确文本与有限像素是系统对照，不是逐字节相同事实可见性的实验。CONTRAST另外增加派生公开统计。
5. **运行顺序和成本**：HF先、native后；native并发36，与HF串行不同。完整冷路径及设备占用缺失，不能做严格等负载效率主张。
6. **资格不等于准确率**：实际完成的prior适配仍有大量无效输出；对原论文方法的结论必须限定到本次适配。
